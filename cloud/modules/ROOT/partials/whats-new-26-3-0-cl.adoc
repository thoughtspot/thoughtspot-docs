[discrete]
=== Enhanced dynamic parameters in charts

Enhanced dynamic parameters are now available to all users and on by default. You can use any parameter from an axis or column name of a chart in the title or description of the Answer which contains that chart. A parameter used in the title or description always displays the value of the same parameter used in the chart itself.

[#26-2-0-cl-secure]
[discrete]
=== Suggestion settings
// Naomi. jira: SCAL-286092. docs jira: SCAL-286093
// PM: Damian.

Suggestion settings are now available to all users who opt in. We have added the Suggestion Settings column to allow you to control data that shows in typeahead suggestions and column knowledge cards. Previously, on Models with row-level security defined, you would see suggested names of data that you could not access in typeahead suggestions or in column knowledge cards.

For example, if you only had access to data in California, you could see that data for Texas existed, although you could not access the data. Set the Suggestion Settings column as *Secure Suggestions* to ensure users never see references to data they shouldn't be able to access. To enable this feature, contact your administrator.
