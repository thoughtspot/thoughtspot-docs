=== SpotterX: Convex and Liveboard agents [.badge.badge-early-access-relnotes]#Early Access#
You can now open Spotter from a Liveboard, and Spotter is now grounded in the context of that Liveboard — its tabs, visualizations, and the effective filters and time ranges applied to each chart.
You can ask questions like "why did revenue drop in Q3?" or "summarize what you see on this Liveboard" and Spotter reads the actual live data behind each visualization to answer, without you having to re-specify your filters or date range.
Multi-step tasks — such as building a forecast, running a why analysis, and charting the result — now stay in a single conversation context across Spotter and Liveboard, with each step tracked so long tasks remain on course.

[#26-11-0-cl-data-cache]
[discrete]
=== Data Cache for modelled sources [.badge.badge-ga-relnotes]#GA#
ThoughtSpot now supports model-level caching with Data Cache. Data Cache copies frequently queried data from your cloud data warehouse into ThoughtSpot-managed storage, so eligible queries are served from the cache instead of running on your warehouse. This means faster answers and lower warehouse compute costs. Once Data Cache is enabled for your cluster, data model editors can turn on caching for individual Models from the new Caching tab in the Model editor. No SQL changes, TML edits, or manual configuration are required. ThoughtSpot automatically routes queries to the cache when the requested data is available, and falls back to your live warehouse when it isn't, so results are always correct. To enable this feature, contact {support-url}.

[#26-11-0-cl-org-deletion]
[discrete]
=== Handling queries post Org deletion [.badge.badge-ga-relnotes]#GA#
Previously, deleting an Org in ThoughtSpot stopped user-initiated queries immediately, but background processes — including scheduled Liveboard reports, alerts, and search indexing — continued to run warehouse queries against the deleted Org's connections for up to 7 days during the deletion grace period, resulting in unexpected warehouse spend.
ThoughtSpot now stops all warehouse query execution for deleted Orgs immediately at deletion time.
Deleted Orgs remain restorable during the grace period; the query block is automatically lifted if an Org is restored.
