=== Writeback for Spreadsheet
ThoughtSpot Spreadsheet view now supports *writeback*, allowing analysts to enter and publish data directly to the cloud data warehouse without leaving ThoughtSpot.
In Spreadsheet view, you can create *input tables* as peer tabs alongside your Answer, define key columns to set the grain, and add editable or formula-based columns. Edits are held in session state until you click *Publish to Warehouse*, ensuring that no unintended writes occur. Published data is immediately available for Search, Liveboards, and Spotter queries.

[#26-11-0-cl-data-cache]
[discrete]
=== Data cache APIs and querygen and dataflow integration [.badge.badge-ga-relnotes]#GA#
ThoughtSpot now supports Model-level caching through *SpotCache*, which materializes frequently queried data from your cloud data warehouse into ThoughtSpot-managed storage so that eligible queries return in under a second at zero warehouse compute cost.
Once an administrator enables caching for your organization, data modelers can turn on caching for individual Models from the new *Caching* tab in the Model editor — no SQL changes, TML edits, or manual configuration required.
ThoughtSpot automatically routes time-bounded queries to the cache when the data is available, and falls back to the live warehouse silently when it is not, so analysts always get correct results.
Cache-served answers display a *data as of* freshness timestamp so you always know when the cached data was last refreshed.

[#26-11-0-cl-org-deletion]
[discrete]
=== Handling queries post Org deletion [.badge.badge-ga-relnotes]#GA#
Previously, deleting an Org in ThoughtSpot stopped user-initiated queries immediately, but background processes — including scheduled Liveboard reports, alerts, and search indexing — continued to run warehouse queries against the deleted Org's connections for up to 7 days during the deletion grace period, resulting in unexpected warehouse spend.
ThoughtSpot now stops all warehouse query execution for deleted Orgs immediately at deletion time.
Deleted Orgs remain restorable during the grace period; the query block is automatically lifted if an Org is restored.
