<h2 id="_new_navigation_and_homepage_coming_soon"><a class="anchor" href="#_new_navigation_and_homepage_coming_soon"></a>New navigation and homepage!</h2>
<div class="sectionbody">
<div class="paragraph">
<p>ThoughtSpot is excited to announce that our brand-new navigation and homepage experience is now enabled by default for all users in this release. This change <b>does not apply</b> to users of ThoughtSpot in an embedded environment.</p></p>
</div>
<h4 id="_highlights_of_the_new_navigation_and_homepage" class="discrete">Highlights of the new navigation and homepage</h4>
<div class="ulist">
<ul>
<li>
<p><strong>Enhanced navigation</strong>: commonly accessed features are now in a left-side navigation menu providing a more intuitive and consistent user experience across all product areas</p>
</li>
<li>
<p><strong>Fewer clicks</strong>: faster and easier to move between key areas, such as between Liveboards, or from a Model to searching data</p>
</li>
<li>
<p><strong>Favorites and Liveboard schedule access</strong>: now available with a single click from the homepage navigation menu, allowing you to quickly find your most important data</p>
</li>
<li>
<p><strong>Modern homepage</strong>: clean, contemporary, and customizable design</p>
</li>
</ul>
