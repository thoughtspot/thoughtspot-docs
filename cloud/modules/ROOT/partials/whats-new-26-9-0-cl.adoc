[discrete]
=== Spreadsheet view in Search data
// Naomi. jira: SCAL-309059. docs jira: SCAL-309060
// PM: Peeyush

You can now view the Answers you create in Search data as spreadsheets, showing only the fields and formulas you included in your search. The top bar of the spreadsheet contains configuration options like changing text alignments, adding formulas, or changing the number format, to further tailor your Answer to your needs.
