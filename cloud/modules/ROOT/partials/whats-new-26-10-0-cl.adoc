=== Spreadsheet on live data [.badge.badge-ga-relnotes]#GA#
// Naomi. jira: SCAL-324098. docs jira: SCAL-324099
// PM: Peeyush. confirm if EA. modify first sentence-- show how to create a spreadsheet from spreadsheet view. add a gif, adding a formula. make more of a splash.

Spreadsheet puts a familiar, editable grid directly on your live data. Open any ThoughtSpot data model, table, or dataset, and every column and formula you add runs as a live query against the governed model, with no export and no stale copy. Formula columns persist as governed logic, while sorting, filtering, conditional formatting, and text and number formatting let you shape the grid on the fly. Save your work as an Answer that stays searchable, shareable, and governed like anything else in ThoughtSpot.


* *Columns and formulas on live data*: Build new metrics with 70+ built-in functions. Every formula runs as a live query and persists as governed logic your team can reuse.
* *Shape your view instantly*: Sort, filter, conditional formatting, and text and number formatting help you focus on what matters, applied live on the data.
* *Save as a governed Answer*: Your spreadsheet becomes a searchable, shareable object with security and lineage intact, never a disconnected export.
* *Built for real datasets*: Scroll seamlessly through large result sets and switch to full-screen mode for focused analysis.

=== Centralized filter window
The centralized filter window is now generally available (GA). This feature introduces a single, unified interface for managing all Liveboard filters. Users can use this to view, update, and apply multiple filters at once, rather than interacting with each filter individually. This feature supports bulk filter changes, clear and reset actions, and provides a streamlined workflow for complex analyses. This improves efficiency, especially when working with Liveboards containing many filters or when users need to adjust several dimensions simultaneously. For more information, see

Spotter analysts are now generally available (GA). You can create Spotter Analysts-- focused, governed analysts that tailor Spotter to a specific team, use case, or domain. Instead of accessing the general Spotter experience, configure the context once: which data models the agent can see, custom instructions that shape its behavior, the connectors it can use, and who the workspace is shared with. [discrete]
=== Writeback for Snowflake [.badge.badge-ga-relnotes]#GA#
ThoughtSpot introduces writeback tables. Writeback with input tables allows you to create and edit tables directly in ThoughtSpot, where you can add new columns and update values. Data is saved back to your cloud data warehouse so you can use these tables across Answers and Liveboards. Currently, we support Snowflake cloud data warehouses. This feature supports planning, and operational workflows, removing the need for spreadsheets or manual uploads. Only users with edit permissions can make changes, and all edits are tracked for governance. For more information, see

xref:writeback.adoc[Writeback].
