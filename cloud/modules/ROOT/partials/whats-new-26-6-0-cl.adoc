[#26-6-0-cl-csv]
[discrete]
=== Spotter CSV upload support

// Naomi. jira: SCAL-293519, SCAL-298380. docs jira: SCAL-293521, SCAL-298381
// PM: Aaghran

You can now upload CSV files directly to Spotter, enabling ad-hoc data analysis without requiring a pre-built data model. This feature makes it faster to explore and get insights from external data files directly in the Spotter interface. Simply click the *+* icon next to the Model selection button in the search bar and select the file you plan to upload. Note that the files you upload remain only in your conversation, and are not added to ThoughtSpot. Files persist in your conversation for up to an hour.
