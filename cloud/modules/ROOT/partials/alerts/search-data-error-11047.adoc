[#search-data-error-11047]

=== 11047

Description:: Formula variables support a special wildcard value: `WILDCARD_ALL`. The result is that the user should have access to all values of the associated column. The associated row-level security (RLS) rule can only be defined with equals `=` and `in`.
+
`region = ts_var('region')`


Resolution:: Update the associated RLS rule to ensure that rules are defined with the operators equals (`=`) or `in`. That is, operators `!=` and `not in` are not supported.
