[discrete]
=== Improved Liveboard chart data freshness
// Mark. jira: SCAL-321861. docs jira: SCAL-?
// PM: Arpit

Liveboard chart data is now automatically refreshed whenever you apply filters or interact with charts using features like Drill Down, Show Underlying Data, Include/Exclude, SpotIQ Analyze, Explain Change, Change Analysis, Custom Actions, or Copy to Clipboard. These actions clear stale cached data for the affected chart, ensuring that your visualizations always reflect the latest data when reloaded. This enhancement improves accuracy and reliability.

[#26-12-0-cl-dark]
[discrete]
=== Dark mode [.badge.badge-ga-relnotes]#GA#
// Mark. jira: SCAL-315145. docs jira: SCAL-343770
// PM: Arpit

ThoughtSpot now supports full dark, light, and system appearance modes across all product surfaces. You can select your preferred theme in your profile menu, and your choice is applied instantly everywhere in the application—including navigation, search, Spotter, editors, Liveboards, and charts. “System” appearance now follows your device’s OS theme automatically. No reload required, and no admin configuration needed.

[discrete]
=== Candlestick chart added to new chart library [.badge.badge-ga-relnotes]#GA#
// Mark. jira: SCAL-299456, docs jira: SCAL-299457
// PM: Anshul

The new charts library expands to add candlestick charts. This update introduces advanced axis configuration, labeling for open, high, low, and close (OHLC) values, faceting and trellis chart modes, improved handling of null values, custom font support, and enhanced tooltips. Multiple attributes create facets for easier comparison, and the new renderer matches the legacy Highcharts candlestick behavior while offering greater flexibility for analysts and dashboard creators.

=== View explanation panel in Spotter answers [.badge.badge-ga-relnotes]#GA#
// Mark. jira: SCAL-341022, SCAL-325193. docs jira: SCAL-343261, SCAL-325194
// PM: Abhijit

A *View explanation* link now appears in Spotter answers when ThoughtSpot can provide a detailed breakdown of how the answer was derived. If your answer card includes a *View explanation* link, you can click it to open a panel where you can see information about how your question was interpreted, which columns and tables were used, and how the result was calculated. Rollout of this feature begins in 26.12.0.cl and will be enabled for all users during a phased GA.
