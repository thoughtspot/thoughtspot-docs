[#26-12-0-cl-rbac]
[discrete]
=== New privileges to control content creation and analysis

// Mary. jira: SCAL-331949. docs jira: SCAL-331950
// PM: Siddhant

Administrators can now use roles to control who can create content and analyze data. These new privileges are available on instances with Roles enabled:

* *Can create Liveboards*: Create, edit, copy, pin to, and delete Liveboards.
* *Can create Answers*: Search data, and create, edit, and save Answers.
* *Can analyze data*: Use Explore, Drill down, Change analysis, and Show underlying data.
* *Can administer schedules*: Manage all schedules in the Org.

All existing and new users have the first three privileges by default, so nothing changes until an administrator revokes a privilege for a group. When a privilege is revoked, the related actions are hidden for those users. All users can still view Liveboards and Answers.
