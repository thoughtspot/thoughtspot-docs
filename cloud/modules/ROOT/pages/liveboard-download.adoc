You can download a Liveboard in PDF format, without downloading each visualization separately.
Follow these steps:

. Go to the *Insights* tab.
. Select *Liveboards*.
. Select a Liveboard from the list of Liveboards by clicking on its title.
. In the open Liveboard, select the *More* menu image:icon-more-10px.png[more options menu icon], and select *Download*.
+
The *Download* window appears.
. Select a PDF format to download.
+
* PDF (continuous) downloads a PDF without page breaks and preserves the layout of the original Liveboard.
+
NOTE: The continuous feature is in Early Access. To enable it, contact {support-url}.
* PDF (A4 pages) downloads a PDF that you can customize to fit in an A4 page format.
. Optionally, select *PDF (A4 pages)*.
.. Under *Format* select one of the following _Format_ output options:
 ** Select *<<pdf-pinboard,Liveboard>>* to generate a PDF that combines several visual Answers on the same page, just like they appear on the Liveboard.
 ** Select  *<<pdf-visualizations,Visualizations>>* to print each visualization on its own page of the PDF file.
.. Under *Layout* select either *Portrait* or *Landscape*.
.. Under *PDF options* select the checkboxes for your desired options.
+
[.bordered]
image:pdf-options.png[See the PDF options: footer logo, include page number, include cover page, and include fitler page(s).]
.. Under *Footer text* enter any text that you would like to appear in the footer of the PDF.
. Optionally, select *PDF (continuous)*.
.. Under *Content* select the checkboxes for your desired options.
+
image::pdf-continuous.png[]

. Click *Download*.

If you do not see the option to download the Liveboard as a PDF, your company may have removed the Liveboard download option. In that case, contact your ThoughtSpot administrator if you would like to download Liveboards.

CAUTION: Scheduled Liveboards support up to 80 visualizations. Including more than 80 can cause schedules and downloads to fail.

== XLSX/CSV download of Liveboards
When you select *Download*, you can select *CSV* and *XLSX* formats in addition to *PDF*. When you select CSV or XLSX, you can choose which visualizations to download and a bulk download of the Liveboard data is triggered instead of a static image.

. Go to the *Insights* tab.
. Select *Liveboards*.
. Select a Liveboard from the list of Liveboards by clicking on its title.
. In the open Liveboard, select the *More* menu image:icon-more-10px.png[more options menu icon], and select *Download*.
+
The *Download* window appears.
. Select *PDF*, *XLSX*, or *CSV* from the drop-down menu.
+
If you select PDF:

.. Under *Format* select one of the following _Format_ output options:
** Select *<<pdf-pinboard,Liveboard>>* to generate a PDF that combines several visual Answers on the same page, just like they appear on the Liveboard.
** Select  *<<pdf-visualizations,Visualizations>>* to print each visualization on its own page of the PDF file.
.. Under *Layout* select either *Portrait* or *Landscape*.
.. Under *PDF options* select the checkboxes for your desired options.
+
[.bordered]
image:pdf-options.png[See the PDF options: footer logo, include page number, include cover page, and include fitler page(s).]
.. Under *Footer text* enter any text that you would like to appear in the footer of the PDF.

+
If you select XLSX or CSV:

.. Under *Download* select either *Full Liveboard*, *Specific visualizations*, or *Tables & Pivot Tables Only*.
.. If you select *Specific visualizations*, select the visualizations that you want to download under *Selected answers*.
+
image::download-csv-xlsx.png[Download selected answers as an XLSX file.]

. Click *Download*.

== Special characters in visualization names during Liveboard export
When you export a Liveboard as a CSV or XLSX file, ThoughtSpot uses the **visualization name** as:

* The **sheet name** in an XLSX (multi-sheet Excel workbook)
* The **file name** for each visualization in a CSV export (ZIP archive)

To ensure compatibility with file systems and Microsoft Excel, ThoughtSpot automatically removes certain special characters from visualization names during export.


=== Characters that are removed

ThoughtSpot removes the following characters from visualization names in exported files.

==== Standard ASCII characters

[cols="1,1,3", options="header"]
|===
| Character | Symbol | Reason Removed

| Backslash
| `\`
| Invalid in file system paths on Windows and Linux

| Forward slash
| `/`
| Invalid in file system paths and Excel sheet names

| Colon
| `:`
| Invalid in file system paths (Windows) and Excel sheet names

| Question mark
| `?`
| Invalid in file system paths and Excel sheet names

| Asterisk
| `*`
| Invalid in file system paths and Excel sheet names

| Left square bracket
| `[`
| Invalid in Excel sheet names

| Right square bracket
| `]`
| Invalid in Excel sheet names
|===


=== Behavior

* Characters are removed — they are not replaced with a substitute character such as a space or underscore.
* The rest of the visualization name is preserved as-is.
* This sanitization applies automatically during export; no configuration or user action is required.
* The content of the exported data is unaffected — only the sheet name or file name changes.

=== Examples

[cols="1,1", options="header"]
|===
| Original Visualization Name | Exported Sheet / File Name

| `Sales:Q1`
| `SalesQ1`

| `Q1/2024`
| `Q12024`

| `Revenue [USD]`
| `Revenue USD`

| `Price￥100` (full-width ￥)
| `Price100`

| `Report：Draft` (full-width :)
| `ReportDraft`

| `What*Matters?`
| `WhatMatters`

|`:/?*[]\`
|`Answer.csv` or `Sheet` for xlsx
|===

=== Why this happens

ThoughtSpot performs character sanitization for two reasons:

* **File system compatibility** — Characters such as `/`, `\`, `:`, `?`, `*`, `[`, and `]` are reserved or invalid in file names on Windows and Linux file systems. Allowing these characters would cause the export to fail or produce unreadable files.

* **Microsoft Excel compliance** — Excel enforces strict rules on sheet names. Sheet names cannot contain `\`, `/`, `:`, `?`, `*`, `[`, or `]`, and must be 31 characters or fewer.

=== Recommendations

To ensure that exported file names and sheet names match your visualization names exactly:

* Avoid using the characters listed above when naming visualizations in your Liveboard.
* For visualizations targeting Asian locale users, prefer standard ASCII characters in visualization names, or verify the exported name after downloading the file.

== Download PDF in Liveboard format
The Liveboard format produces a PDF file that looks very similar to the Liveboard inside ThoughtSpot.
The highlights and insights appear at the top, and the rest of the Liveboard is on a rectangular grid, with natural page breaks.

Follow these steps to specify additional options:

. Under *Format*, select *Liveboard*.
. Under *Layout*, select either the _Landscape_ or _Portrait_ page orientation.
. If the Liveboard has multiple tabs, you see the *Select tabs to download* option. Select the specific tabs you would like to download, or select *All* to download all tabs. By default, ThoughtSpot includes all tabs in the PDF.
. Under *PDF Options*, select or deselect *Include page number*, *Include cover page*, or *Include filter page(s)*.
. Select *Download*.

[.bordered]
image::liveboard-export-liveboard-tabs.png[PDF export as Liveboard]

NOTE: If you choose to exclude cover and filter pages from a PDF, and the PDF contents fit on a single page, a blank page is appended to the PDF.


[#pdf-visualizations]
== Download PDF in Visualizations format

When you select *Visualizations*, you can choose to print all, or some, of the visualizations in the Liveboard.
The highlights and insights appear at the top, and the rest of the visualizations get their own page.

Follow these steps to specify additional options:

. Under *Format*, select *Visualizations*.
. Under *Layout*, select either the _Landscape_ or _Portrait_ page orientation.
. Under *PDF Options*, select or deselect *Include page number*, *Include cover page*, or *Include filter page(s)*.
+
NOTE: This is an early access feature. To enable this feature, contact your administrator.
. Under *Content*, specify if you want the table visuals to end after filling the whole page by selecting the _Truncate Tables_ option.
+
NOTE: If you choose not to truncate tables, the page number and footer will appear only on the last page of the table. Note that page length of a non-truncated table will still count towards total page length of the pdf.
. Under *Visualizations*, select the visualizations you want in the PDF.
Deselect any visualizations you do not want. If your Liveboard has tabs, you can also select or deselect tabs to include in the PDF.
. Select *Download*.

image::liveboard-viz-export-tabs.png[PDF export as Visualizations]

[#pdf-width]
== Change PDF width

By default, Liveboard PDFs download at a width of 1920 pixels, which supports most Liveboard visualizations and layouts. To change this default width to a different width in pixels for your company, contact {support-url}. For example, if most users in your company view ThoughtSpot in full screen, request that ThoughtSpot set the Liveboard PDF width to the full screen width.

[#pdf-examine]
== Examine the PDF

After the download completes, examine your PDF.

Notice that the PDF produced in *Liveboard* mode combines the visuals on the page in the same manner as the original Liveboard.
Contrast this with the PDF produced in *Visualizations* mode: this PDF combines the small adjacent indicator and KPI visuals at the top, and all other visuals and tables appear on their own page.
