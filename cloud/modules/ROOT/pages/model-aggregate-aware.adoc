= Aggregate-aware Model switching
:page-last_updated: 03/03/2026
:linkattrs:
:experimental:
:page-layout: default-cloud-beta
:description:
:jira: SCAL-284295, SCAL-284296

Aggregate-aware Model switching in ThoughtSpot allows you to define multiple Models at different levels of aggregation. You could create detailed and summarized models. Then, when a user queries the data, ThoughtSpot automatically and switches between these Models based on the granularity of the query. The user does not need to manually switch between Models.

For example, if a user asks for yearly or monthly data, the system will use the summarized or aggregate model. If they drill down to daily or transactional data, ThoughtSpot will switch to the detailed model.

This helps to optimize query performance and reduce costs.
