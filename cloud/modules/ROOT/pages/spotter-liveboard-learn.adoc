Learning from Liveboards helps Spotter learn reusable context from selected Liveboards and apply that context when answering questions on related data models.

NOTE: To enable this feature, contact {support-url}.

Only users with data model access can use this feature.

== Using Learn from Liveboard

To optimize your data model using Learn from Liveboard, follow these steps:

. In the Data workspace, click the name of the Model you want to optimize for Spotter.
. In the Model, click the *More* menu image:icon-more-10px.png[Chart configuration icon image], and select *Enable Spotter*.
. Click the *Spotter optimization* tab.


. Under *Learn from liveboard*, click *Learn*.
+
[.bordered]
image::learn-from-liveboard.png[Learn from liveboard]

. In the selection pop-up, choose associated for dependent Liveboards and click *Learn*. We recommend beginning by selecting one or two Liveboards.
+
[.bordered]
image::liveboard-learn-select.png[Select Liveboards to learn from.]

. The background generation should complete in five to ten minutes. During processing, a loader appears while memory generation runs in the background.

. Open *View memory* to review the generated memory and learned context.
+
[.bordered]
image::liveboard-learn-memory.png[Click View memory and review the generated memory.]

. Open memory summary to review related questions, then validate behavior in Spotter conversations on the same Model.
+
[.bordered]
image::liveboard-learn-memory-summary.png[View memory summary to see related questions.]

== Expected behavior

After memory is generated, Spotter may fetch this learned context during conversation and produce responses that reflect this additional context.

Be sure to validate the context by asking representative questions in Spotter to compare answer quality before and after learning.

== Troubleshooting

If Learn from Liveboard is not working, check the following requirements:

* Confirm the user has data model edit access.
* Run learning again with one or two Liveboards, and wait the full five- to ten-minute window.
* Check whether memory appears in *View memory*.
* Validate in conversation with questions related to the selected Liveboards.
* Review the *Thinking* section to verify whther additional context is being fetched while generating a response.

== Limitations

* You cannot currently edit generated memory.
* You cannot currently modify or delete individual learned rules, you can only delete the full memory object.
* Learning can apply across associated data models that selected Liveboards are built on.
* Processing is asynchronous and can take at least five to ten minutes.
