== Focused Homepage

image::spotter-answer3.png[]

ThoughtSpot now opens to a focused home page built around Spotter, so the first thing you see is a natural-language prompt and the content you use most. Administrators can roll it out across every Org or a few, and tailor what each team lands on.

[.key-update.tag-early-access]
== Command palette

video::https://www.thoughtspot.com/whats-new/july-2026-highlights.mp4[]

Reach anything in ThoughtSpot with a single keystroke. The command palette brings search and navigation into one overlay, so you can jump to Liveboards, Answers, and Models, run common actions, and keep working without ever leaving the keyboard.

[.key-update.tag-beta]
== SpotterViz Insight tiles

image::search-mode.png[]

Insight tiles bring AI-written analysis onto any Liveboard. Set the interpretation instructions and the signals worth watching, and every refresh runs them for you, turning raw numbers into clear summaries, trends, and callouts teams can act on.

== Scheduled subscriptions

Deliver Liveboards and Answers on a recurring schedule. Pick the cadence, format, and recipients once, and ThoughtSpot sends everything automatically, so stakeholders always open the latest numbers without logging in or chasing a fresh copy by email.

== Natural language search

image::spotter-approve-mapping-grey.png[]

Ask questions in plain English and get governed Answers back in seconds. Spotter interprets intent across every connected model, resolves the right columns and filters, and returns the closest match with the data lineage you already expect.

[.tag-early-access]
== Custom calendars

Define fiscal periods that fit how your business actually reports. Quarters, weeks, and custom periods flow through automatically, so reports, filters, and growth metrics respect the calendar you set on each worksheet without any manual math.

== Liveboard tabs

Group related visualizations into tabs on a single Liveboard. Readers move between topics without leaving the page, losing their filters, or opening five separate boards, and authors keep everything organized in one tidy, shareable place.

[.tag-beta]
== Bulk permission sync

Apply sharing changes across many objects at once. Update groups, roles, and object access in a single guided pass instead of one item at a time, and preview exactly who gains or loses access before you commit anything to production.
