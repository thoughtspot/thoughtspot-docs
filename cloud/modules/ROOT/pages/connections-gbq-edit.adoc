You can edit a {connection} connection to add tables and columns.

To edit a connection:

ifndef::spotter[]
. Navigate to *Data workspace* > *Connections*.
endif::[]

ifdef::spotter[]
. Click the app switcher menu image:spotter-app-switcher.png[Spotter app switcher] and then click *{form-factor}*.
. On the left side of the screen, select *Manage data > Manage data sources*.
. On the _Data workspace_ page, click *Connections*.
endif::[]
. Select the name of the connection you want to edit.

. Select the name of the connection you want to edit.
. Click *Edit*

. You can now change the connection name and update the connection details, by selecting the appropriate option at the top of the screen, making any changes needed and clicking *Next* to go to the next page.

. Expand the database table dropdown menu, and select the tables and columns you want to add.

. Click *Next*, and then click *Update connection* to save the updated connection.
+
[TIP]
====
To save your changes without completing all steps, click *Save and exit* on the connection configuration step.
ThoughtSpot saves your changes and returns you to the connection details page.
====



[#validate-metadata]
== Validate metadata

You can now validate connections to discover any changes in metadata after the connection was created. When you validate a connection, ThoughtSpot provides a JSON file containing details on any metadata changes. Once alerted to a metadata change, you can use TML to update the connection.

To validate your connection:

ifndef::spotter[]
. Navigate to *Data workspace* > *Connections*.
endif::[]
ifdef::spotter[]
. Click the app switcher menu image:spotter-app-switcher.png[Spotter app switcher] and then click *{form-factor}*.
. On the left side of the screen, select *Manage data > Manage data sources*.
. On the _Data workspace_ page, click *Connections*.
endif::[]

. Select the name of the connection you want to validate.

. Click *Validate*.

. If ThoughtSpot detects any changes to the connection's metadata, it displays an appropriate message. Else, it gives a message stating successful validation.

To remove a table from a connection, delete it from the connection details page.
For more information, see: xref:connections-gbq-delete.adoc[Delete a table].

See the xref:connections-gbq-reference.adoc[Connection reference] for details of connection parameters.
