== Connect to Arrow Flight SQL

. Log in to {product} and follow the steps to xref:analyst-studio-connecting-analyst-studio-to-your-database.adoc#direct-connect[connect a database to {product}].
. Click the *Search databases* dropdown and select *Arrow Flight SQL*.
. Enter the Display name, Description (optional), Host, and Port.
. Select the authentication method as password or token.
.. For password, enter username and password.
.. For token, enter the token.
. Upload a file for the Custom Trusted SSL CA certificate, and select the preferred JDBC driver.
. Click *Connect*.
You will land on a page that displays your database schema.
