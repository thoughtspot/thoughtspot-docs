The following release notes cover weekly changes to the ThoughtSpot Cloud release. These enhancements and fixes are automatically deployed to customer instances. For the latest monthly release notes see the xref:notes.adoc[{version} release notes].

There are two types of weekly releases:

* *Patch releases*: which apply only to the {version} release.
* *MT releases*: which apply to multiple release versions.
{empty} +

[tabs]
====
