This lets you start analyzing data within seconds, while richer styling and formatting are applied automatically.

== How progressive rendering works

Progressive rendering operates in two phases for Spotter answers that use Muze AI-generated charts:

// SOURCE: SCAL-330485 description - "Spotter answers that use Muze AI chart generation"

1. *Base chart (v1)* — The charting engine generates a functional, interactive chart with correct axes, data series, and basic formatting. The chart displays immediately.
2. *Background enhancement (v2)* — While you interact with the base chart, the system applies additional enhancements in the background:
** Refined color schemes and styling
** Data labels and annotations
** Legend positioning and formatting
** Axis formatting improvements
** Additional interactive elements

// SOURCE: SCAL-330485 description - "baseline chart chosen by Muze AI's fast mode (v1)... Muze AI refinement (v2)"

When enhancements complete, they merge into the base chart. The transition is smooth and does not require a page refresh or manual action.

Because enhancement runs after the answer's data has been served, it becomes data-aware. The system computes per-measure statistics from the actual result set and sends them to Muze AI, enabling smarter choices about axis domains, binning, and formatting that were not possible in the previous synchronous flow.

// SOURCE: SCAL-330485 description - "per-measure statistics computed from the actual result set... enabling smarter choices about axis domains, binning, and formatting"

Progressive rendering is available for Spotter answers that use Muze AI-generated charts.

== What to expect

=== Phase 1: Base chart

When you receive a Spotter answer with a Muze AI-generated chart:

// SOURCE: SCAL-330485 description - "Spotter answers that use Muze AI chart generation"

* A loading indicator may appear briefly
* The base chart renders with:
** Correct chart type (for example, line, bar)
** Axes and scales
** Data series
** Basic legend

The base chart is fully interactive. You can hover, pan, zoom, and toggle series immediately.

=== Phase 2: Enhancement

While you work with the base chart, the system:

* Applies AI-recommended styling based on data-aware statistics
* Adds data labels if appropriate
* Refines axis formatting and binning
* Adjusts colors and visual encoding

[NOTE]
====
The exact timing depends on the complexity of the data and the chart.
Simple charts may complete enhancements quickly.
Complex charts with multiple series, annotations, or custom formatting may take longer.

// TODO: verify with engineering — confirm whether typical enhancement timing should be documented
====

=== Phase 3: Final chart

When enhancements complete:

* The chart updates visually with the improved formatting
* No manual refresh is required
* All interactivity is preserved

== Interacting during progressive rendering

You do not need to wait for enhancements to finish before using the chart:

* Hover over data points to see values
* Toggle series on and off using the legend
* Pan and zoom to explore data
* Submit xref:charts-agentic-nl-editing.adoc[natural-language chart editing] requests

Any changes you make to the chart while enhancements are in progress take precedence and are applied after the current enhancement cycle finishes.

// SOURCE: SCAL-330485 description - "concurrent user edits always win over the background write"

== Behavior guarantees

Progressive rendering is designed to be fail-safe:

* If the background enhancement fails, times out, or encounters a race condition, the base chart (v1) remains visible with no user-facing error.
* Concurrent edits always take priority over background writes.
* Enhancements run on an isolated worker pool, so a slowdown in the Muze AI service does not affect other requests.

// SOURCE: SCAL-330485 description - "fail-safe by construction... any failure, timeout, or race in the background path leaves the v1 chart standing with no user-facing error... concurrent user edits always win over the background write... Enrichment runs on an isolated worker pool"

== Limitations

* Progressive rendering applies to Spotter answers with Muze AI-generated charts only. Standard token-based charts use the existing rendering pipeline.
* The base chart may appear with minimal styling (for example, default colors, no data labels) before enhancements complete.
* The feature is Spotter-only and is enforced on both the client and server.
