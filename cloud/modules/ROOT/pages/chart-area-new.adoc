== Understanding new area charts

New area charts display quantitative data graphically.
The area between the x-axis and the line are colored in to help you compare different portions of the chart.

[.bordered]
image::area_chart_new_example.png[Example image for an area chart]

Your search needs at least one attribute and one measure to be represented as an area chart.

== Supported configurations

* Multivariate charts
* Multiple measure lines in a single shared axis
* Multiple measure lines in a dual axis, where each measure line is a part of either axis.

== Automatic transformations
* Shared axis - Automatically apply MN/MV for measures in a shared axis and auto apply identity transform
* Dual axis -  Automatically apply `transform type == identity`


== Limitations
* Shared axis configuration is not supported.
* Dual-axis configuration is not supported.
