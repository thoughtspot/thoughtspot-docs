Learn more about ThoughtSpot's plug-ins.

* The xref:thoughtspot-sheets.adoc[Google Sheets add-on] allows you to connect to a ThoughtSpot instance, pull daata directly into a Google Sheet, and use the tools in Google Sheets for ad-hoc analysis.
* The xref:thoughtspot-slides.adoc[Google Slides add-on] allows you to insert charts and live data visualizations into a Google Slides presentation.
* The xref:thoughtspot-excel.adoc[Microsoft Excel add-in] allows you to connect to a ThoughtSpot instance and pull data directly into an Excel sheet for ad-hoc analysis.
* The xref:thoughtspot-powerpoint.adoc[Microsoft PowerPoint add-in] allows you to connect to a ThoughtSpot instance and pull data directly into a PowerPoint slide sheet for ad-hoc analysis.
* The xref:salesforce-plugin.adoc[] allows you to access interactive ThoughtSpot dashboards and AI-driven search without leaving Salesforce.
* The xref:spotter-ms-teams.adoc[Spotter in Microsoft Teams plug-in] allows you to ask questions to Spotter directly within Microsoft Teams.
* The xref:spotter-app-for-slack.adoc[Spotter app in Slack] allows you to add Spotter to a channel and ask questions on your data sources in natural language.
