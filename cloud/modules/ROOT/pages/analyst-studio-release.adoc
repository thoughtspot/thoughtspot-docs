== March 10, 2026

Local file upload:: Not every piece of data lives in a cloud drive. Sometimes, the insight you need is sitting in a one-off export on your desktop. We’ve removed the friction of moving files to the cloud just to see them in ThoughtSpot. Now, you can upload local files directly, with a smart new processing engine that helps you clean as you go. Simply drag and drop .csv, .tsv, and .xlsx files directly from your computer to start analyzing instantly.
+
What's new;;
+
--
* Smart header detection: Tell us if your file has headers or not; if it doesn't, we’ll generate them and identify data types from the very first row.
* Precision data profiling: Review a 5-row sample and toggle off columns you don't need before the dataset is even created.
* Flexible typecasting: Manually override detected data types (like changing a String to a Date) using our new type-logic validator.
--

== February 26, 2026

Data mashup for cross-source joins [.badge.badge-early-access]#Early Access#::
Data Mashup is a high-performance interface for performing SQL transformations across disparate data sources within a single Report. It removes the "single connection" restriction, enabling joins between different warehouses and flat files without requiring an ETL process to centralize data first.
+
Key Features:

--
* Cross-Source Joins: Perform standard SQL joins across independent datasets.

* Fast operations: Uses a cached layer to treat external datasets as local tables for high-performance search.

* Sources: Supports SQL and flat file datasets; Notebook outputs and CSV/Excel support are coming soon.
--
+
For more information, see xref:analyst-studio-query-datasets.adoc[].

== February 12, 2026

New and improved SQL Editor::
We have overhauled the SQL Editor to make writing queries smoother, faster, and more customisable - from "mind-reading" autocomplete to a high-performance editor interface.

Enhanced autocomplete;;
* Advanced parsing: Full support for CTEs, quoted/case-sensitive table names, and non-aliased JOINS.
+
* Flexible syntax: Recognises tables separated by commas and multiple queries separated by semicolons.

Better customisation and UX;;
* Visuals: New High-Contrast theme, font sizes (10–24px), and Minimap toggle.

* Organization: Use `-- #region` / `-- #endregion` for code folding.

* Editing tools: Added Mouse-wheel zoom, and dedicated Undo/Redo buttons.

Performance boost;;
* Instant suggestions: We now fetch table and column metadata in parallel to eliminate wait times.

* Lag-free typing: Optimised rendering ensures the UI stays snappy even when handling massive queries.

== December 15, 2025

Microsoft Excel Connection:: Connect directly to Excel Workbooks in OneDrive and SharePoint for live, self-service data analysis.

Now, analysts and business users can connect Analyst Studio directly to Excel workbooks stored in Microsoft OneDrive and SharePoint Online. This integration enables self-service data ingestion, allowing you to quickly onboard ad hoc or external data without IT bottlenecks, and support data mashups within Analyst Studio.
The connection is read-only (your original Excel file is never modified) and uses the Microsoft Graph API for secure, scheduled refreshes.

Crucial steps and best practices:

* Admin setup required: Before analysts can use this feature, an Analyst Studio Admin must enable the Microsoft Excel Integration and grant necessary consent in Azure AD.
* Data location matters: Use files stored in SharePoint Online for shared, production reports, as access is tied to the team/site. Use OneDrive only for personal, draft analysis.
* Prepare your data: Ensure your Excel workbook uses the first row for headers and avoids merged cells. The system imports the final calculated value of any formula, not the formula itself.
* Supported format: Only files in the .xlsx format are supported.

To learn more, see xref:analyst-studio-excel-workbook-integration.adoc[Excel integration].


== November 19, 2025

We released quality-of-life improvements designed to give you better visibility into your data flow and safeguards against accidental data loss.

Enhanced publish notifications:: You will now receive immediate notifications if a publish fails, along with specific details on the issue.

Workspace monitoring:: The system will now alert you instantly if your workspace exceeds its data size limits, ensuring you are aware of capacity constraints before attempting further operations.

Safer deletions:: To prevent breaking changes, datasets in {product} can no longer be deleted if they have active dependents in ThoughtSpot. The system now provides a list of these dependents so you can manage them safely.
+
NOTE: This feature requires a ThoughtSpot release version of 10.13.0.cl or later, and applies only to newly-created datasets.

== November 12, 2025

Data retention policy:: The new Data Retention Policy empowers Workspace admins to manage how long Report result data is stored in Analyst Studio. Admins can now set workspace-level retention periods (7–365 days), after which an automated daily purge deletes older report PDFs, query results, notebook outputs, and dataset data. Query and run histories are preserved, but their underlying results are cleared. For more information, see xref:analyst-studio-data-retention.adoc[]

== July 28, 2025

Python notebooks now support Snowpark and PySpark:: Both libraries unlock powerful data engineering and analytics workflows directly within your notebooks.
+
Snowpark empowers you to build scalable data pipelines and run advanced data transformations using Snowflake’s engine.
+
PySpark provides distributed data processing and machine learning capabilities via Apache Spark, enabling efficient analysis of large datasets.

This feature gives administrators greater oversight and control over how often users can schedule updates. Learn more xref:analyst-studio-admin-managed-schedules.adoc[here].

== May 8, 2025

Python upgrade:: We’re upgrading our Python environment from version 3.9 to 3.11. This update brings:
+
–
Performance boost: Faster execution thanks to core optimizations.
Better error messages: Clearer tracebacks to speed up debugging.
New language features: Includes match statements (structural pattern matching), precise error locations, and improved typing.
Deprecations: Some older libraries or syntax may no longer be supported—please review your code for compatibility.

–
+
For most users, no changes are required. If you maintain custom Python code, we recommend testing it in the Python 3.11 environment (Python Edge). Learn more about supported library versions xref:analyst-studio-notebook.adoc#supported-libraries[here].
