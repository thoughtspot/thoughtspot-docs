== Memory export options

=== Liveboard-generated memory

**Option 1 — Regenerate at the destination (recommended)**

If the source Liveboard is available in the target Org or cluster, migrate the Liveboard there and run memory generation again. Spotter will learn directly from the Liveboard in the new context — the generated memory will reflect that Org's data, not a copy from another environment.

**Option 2 — Copy from download, teach in conversation**

1. Download memory from the Memory Sources page on the source Org.
2. Open the downloaded file — it contains the memory entries as readable text.
3. In a Spotter conversation on the target Org, paste a batch of entries and ask Spotter to save them:

> *"Remember the following definitions for this data model: [paste batch]. Save each one."*

Work through the file in batches — 5 to 10 entries at a time keeps the conversation focused. Confirm each batch before moving to the next.

=== Conversation-generated memory

Use the same copy-from-download approach above. Download memory from the source org, paste batches into a conversation on the target org, ask Spotter to save each batch.
