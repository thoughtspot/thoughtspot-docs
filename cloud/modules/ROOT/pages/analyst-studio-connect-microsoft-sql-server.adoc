== Connect to Microsoft SQL Server

. Log in to {product} and follow the steps to xref:analyst-studio-connecting-analyst-studio-to-your-database.adoc#direct-connect[connect a database to {product}].
. Select *Microsoft SQL Server*.
. Enter the Display name, Description (optional), Host, Instance, Port, and Database name.
. Select the Authentication method from the dropdown.
.. For Default, enter Username and Password.
.. For ActiveDirectoryServicePrincipal, enter PrincipalID and PrincipalSecret.
.. For ActiveDirectoryPassword, enter Username and Password.
. Upload a file for the Custom Trusted SSL CA certificate.

. Select the preferred JDBC driver.
. Click *Connect*.
You will land on a page that displays your database schema.
