The Spotter Connector Marketplace is a browsable catalog of third-party connectors that extend Spotter's capabilities by connecting it to external tools and services through the link:https://modelcontextprotocol.io/[Model Context Protocol (MCP), window=_blank].
// SOURCE: PDM-4465

The marketplace replaces the previous connectors list on the Spotter page with two sections:

* **My added connectors**: Connectors already configured on your ThoughtSpot instance.
* **Available to add**: A catalog of over 100 pre-configured connector templates that you can browse and add.
// SOURCE: demo transcript

All Spotter users can browse the marketplace and see available connectors. Adding and configuring connectors requires administrator privileges or the *Can Manage Spotter* privilege, and must be done from the primary Org.
// SOURCE: demo transcript

If a connector you need is not listed in the catalog, you can connect Spotter to any MCP-compatible server by providing its URL and credentials.
// SOURCE: PDM-4465, demo transcript

The marketplace includes connectors with different setup requirements:

== User roles and permissions

The Connector Marketplace is visible to all Spotter users, but the actions available depend on your role and your current Org.
// SOURCE: demo transcript

=== Primary Org

[cols="1,3", options="header"]
|====
| Role | Available actions

| Administrator
| Browse the catalog, add, configure, and edit connectors, share connectors, manage permissions.

| Can Manage Spotter privilege
| Browse the catalog, add and configure connectors, share connectors, manage permissions.

| End user
| Browse the catalog and view added connectors (view-only). Cannot add, configure, or manage connectors.

|====

=== Non-primary Orgs

Connectors can only be added or removed from the *primary Org*. If you are in a non-primary Org:

* **Administrators and users with Can Manage Spotter**: Can browse the catalog, share connectors, and manage permissions. The *Add* option is not available.
* **End users**: Can browse the catalog and view connectors they have access to (view-only).
// SOURCE: demo transcript

For details, see <<_sharing_a_connector>> and <<_managing_connector_permissions>>.

[NOTE]
====
The *Can Manage Spotter* privilege for connector management is available starting with the first patch of 26.10.0.cl.
// SOURCE: demo transcript
====

== Accessing the Connector Marketplace

The Connector Marketplace is available on the *Spotter* page.
// SOURCE: demo transcript

. Navigate to the *Spotter* page.
. Click *Settings*, then click *Connectors*.
+
The marketplace displays your added connectors and the full catalog of connectors available to add.

== Adding a connector

You must be an administrator or have the *Can Manage Spotter* privilege, and you must be in the *primary Org* to add a connector.
// SOURCE: demo transcript

=== Connectors that require setup

Most connectors in the marketplace are pre-configured templates. To add one of these connectors:
// SOURCE: demo transcript

. In the Connector Marketplace, locate the connector in the *Available to add* section.
. Click the connector to open its *Add connector* window.
. Follow the link at the top of the window to the provider's documentation and complete any required setup on the provider's side. This typically involves registering an application and obtaining credentials such as a URL, client ID, and client secret.
. Return to the *Add connector* window in ThoughtSpot and enter the required credentials.
. Click *Add* to complete the setup.
// TODO: verify with engineering — confirm the exact button labels and form fields in the setup flow.

+
Some connectors have a known MCP server URL. In these cases, ThoughtSpot pre-fills the URL for you, and you only need to provide authentication credentials.
// SOURCE: demo transcript

=== One-click connectors

Some connectors, such as Slack and Web Search, can be added with a single click and require no additional configuration.
// SOURCE: demo transcript

To add a one-click connector:

. In the Connector Marketplace, locate the connector in the *Available to add* section.
. Click *Add*.
+
The connector is added immediately and appears in *My added connectors*.

== Sharing a connector

After a connector is added, administrators and users with the *Can Manage Spotter* privilege can share it with users and groups. Sharing controls which users see the connector in their *Added* connectors list and can use its capabilities in Spotter conversations.
// SOURCE: demo transcript — sharing confirmed as an available action; end users "see the connectors that have been added for you, that you have access to"

Unlike adding connectors, sharing is available in both the primary Org and non-primary Orgs.
// SOURCE: demo transcript

To share a connector:

. In the Connector Marketplace, locate the connector in *Added* connectors list.
. Click the *More* menu icon image:icon-more-10px.png[More menu icon image] for the connector and select *Share*.
// TODO: verify with engineering — confirm the exact UI control (options menu, button label) for the share action.
. Select the users or groups you want to share the connector with.
// TODO: verify with engineering — confirm whether sharing supports both users and groups, and whether there are distinct access levels (for example, view vs. use).
. Select *Share*.

The connector now appears in the *Added* connectors list for the selected users.

== Managing connector permissions

Administrators and users with the *Can Manage Spotter* privilege can manage the permissions of an added connector, in both the primary Org and non-primary Orgs.
// SOURCE: demo transcript — "you kind of also have this share and manage permissions"

To manage permissions for a connector:

. In the Connector Marketplace, locate the connector in *Added* connectors.
. Click the *More* menu icon image:icon-more-10px.png[More menu icon image] for the connector and select *Manage Permissions*.
. Review and update the tool permissions for the connector.
. Click *Save*.

[NOTE]
====
In non-primary Orgs, *Share* and *Manage permissions* are the only connector management actions available. Connectors can only be added or removed from the primary Org.
// SOURCE: demo transcript
====

== Remove a connector

To remove a connector, you must be an administrator or have the *Can Manage Spotter* privilege, and you must be in the *primary Org*.
// SOURCE: PDM-4465, demo transcript

CAUTION: When you remove a connector, all users on your ThoughtSpot instance will lose access to it.

To remove a connector:

. In the Connector Marketplace, click the *More* menu icon image:icon-more-10px.png[More menu icon image] for the connector and select *Remove*.
+
The *Remove connector?* confirmation message appears.
. Click *Remove*.

== What end users see

After the Connector Marketplace is enabled, all Spotter users can access the connectors page, regardless of their role. End users see:
// SOURCE: demo transcript

* **My added connectors**: The connectors that have been configured and shared with them.
* **Available to add**: The full catalog of available connectors. End users can browse this list to see what connectors exist, but cannot add or configure them.

This visibility helps end users understand what integrations are available and make informed requests to their administrators.
// SOURCE: PDM-4465, demo transcript
