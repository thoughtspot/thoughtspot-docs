The Spotter Connector Marketplace is a browsable catalog of third-party connectors that extend Spotter's capabilities by connecting it to external tools and services through the link:https://modelcontextprotocol.io/[Model Context Protocol (MCP), window=_blank].
// SOURCE: PDM-4465

Using the marketplace, all Spotter users can discover available connectors, view their descriptions and statuses, and search for specific tools — regardless of whether the connector is installed or whether the user has permission to install it. Installation and configuration remain permission-gated so that administrators retain full control over the organization's connected surface.
// SOURCE: PDM-4465

== Overview

The Connector Marketplace provides a central location for discovering and managing integrations between Spotter and third-party services. With support for 100+ third-party connectors, the marketplace helps your organization:
// SOURCE: SCAL-326028

* **Discover integrations**: Browse and search the full catalog of available connectors, even if they are not yet installed on your instance.
* **Understand connector capabilities**: View what each connector does, its current status, and whether it is installed.
* **Request or install connectors**: Depending on your role, install connectors directly or make informed requests to your administrator.
* **Add custom MCP servers**: Permitted users can connect Spotter to any MCP-compatible server by providing its URL and credentials.
// SOURCE: PDM-4465

The Connector Marketplace is available on ThoughtSpot Cloud instances running version 26.11.0.cl or later with the Spotter feature enabled.

== Browsing and searching connectors

The marketplace allows you to browse all available connectors in one place.

=== Browsing the catalog

The connector catalog displays all available connectors with the following information for each:

* **Connector name**: The name of the third-party service or tool.
* **Description**: A summary of what the connector does and how it extends Spotter.
* **Status**: Whether the connector is installed, available, or requires configuration.

== Installing a connector

Administrators can install connectors directly from the marketplace.

To install a connector:

. In the Connector Marketplace, locate the connector you want to install.
. Click *Install* or *Configure*.
// TODO: verify with engineering — confirm the exact button label and installation flow
. Follow the on-screen prompts to provide any required credentials or configuration details.
. After installation, the connector status updates and Spotter can use the connector's capabilities.

[NOTE]
====
Each connector may require different credentials or configuration parameters. Refer to the connector's description for specific setup requirements.
====

== Adding a custom MCP server

Spotter works with any MCP-compatible server. If the tool or service you need is not listed in the marketplace catalog, you can add it as a custom connector by providing the MCP server's URL and credentials.
// SOURCE: PDM-4465

To add a custom MCP server:

. In the Connector Marketplace, click *Add custom connector* or *Add MCP server*.
// TODO: verify with engineering — confirm exact button label and flow
. Enter the MCP server URL.
. Provide the required authentication credentials.
. Click *Save* or *Connect*.
. Spotter validates the connection and, if successful, the custom connector appears in your connector list.

[IMPORTANT]
====
Adding a custom MCP server requires administrator privileges. Ensure that the MCP server you are connecting to is trusted and complies with your organization's security policies.
====

== Managing installed connectors

Administrators can manage connectors that are already installed on the instance.

Available management actions include:

* **View status**: Check whether an installed connector is active, inactive, or experiencing errors.
* **Reconfigure**: Update credentials or configuration parameters for an installed connector.
* **Remove**: Uninstall a connector that is no longer needed.
