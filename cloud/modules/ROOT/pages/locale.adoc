== Number and date formatting changes
// Rani. jira: SCAL-345830. docs jira: SCAL-350136. source: "JDK 17 Locale Format Sign-off" table in Sidharth's Slack thread.
// PM: Sejal (sign-off). Eng: Abhishek Ranjan, Sidharth Mishra.

ThoughtSpot Cloud 26.11.0.cl upgrades to a newer version of Java, which includes updated international locale data. As a result, some numbers, currencies, and dates are formatted slightly differently in the following locales. Your data and ThoughtSpot features do not change.

[options="header",cols="2,2,5"]
|===
| Locale | Where you see the change | What changes

| Arabic (Saudi Arabia) (ar-SA)
| Downloaded files (CSV, XLSX, and PDF), scheduled Liveboard emails, and KPI alerts
a| * *Currency*: The currency symbol appears after the number instead of before it.
* *Percent*: An invisible Arabic letter mark is added after the percent sign. The value looks the same, but text comparisons and copied values can differ.
* *Short date and time*: A comma separates the date and the time.

| English (India) (en-IN)
| KPI alerts
| *Currency*: The space after the rupee sign is removed. For example, `₹ 1,234,567.89` becomes `₹1,234,567.89`.

| Français (France) (fr-FR)
| KPI alerts
| *Numbers and currency*: The thousands separator changes from a no-break space to a narrow no-break space. The value looks almost the same, but text comparisons and copied values can differ.

| 中文(简体) (zh-CN)
| KPI alerts
| *Currency*: The yuan sign changes from the full-width `￥` to `¥`.
|===

Formatting in all other locales, including English (United States), does not change.
