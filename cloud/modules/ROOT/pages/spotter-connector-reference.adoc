[.lead]
The Spotter connector marketplace includes over 100 pre-configured connector templates for popular enterprise tools and services. This page lists every connector currently available.

For information on how to add, configure, and manage connectors, see xref:spotter-connector-marketplace.adoc[Spotter connector marketplace].

If the connector you need is not listed here, you can connect Spotter to any MCP-compatible server by adding a custom connector. See xref:spotter-connector-marketplace.adoc#add-custom-connector[Adding a custom connector].

== Featured connectors

Featured connectors are highlighted in the marketplace for their broad enterprise value. Some are fully managed by ThoughtSpot and require no configuration.
