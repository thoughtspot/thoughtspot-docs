The new line stacked column chart is similar to the line column chart, except that it divides its columns with an attribute in the legend. The line stacked column chart combines xref:chart-column-stacked-new.adoc[new stacked column] and xref:chart-line-new.adoc[new line] charts.
There are two y-axes, one for each measure.

[.bordered]
image::line-stacked-column-chart-new-example.png[Stacked line column chart example]

== Supported configuration
* A line-column chart supporting 'n' measures for the line axis and one measure for the column axis.

== Automatic transformations
* A dual-axis setup is created.
* Line measures share one axis, represented by an "MV" construct with an identity transform.
* The column measure occupies the second, single-measure axis.


== Limitations
* No more than 1 measure can be added to the column axis.
* A third axis entity is not allowed.
* Neither axis entities can be removed nor emptied.
* Internal dual-axis configuration is not supported for the line axis
