The *Admin* page is the control center for ThoughtSpot administrators.
From here, you manage users and groups, configure security and authentication,
control access to data, and customize the look and feel of your ThoughtSpot
instance.

Only users with administrator privileges can access the Admin page.

== What you can do from Admin

=== Users
Create, edit, and deactivate user accounts.
Assign users to groups, set passwords, and manage account activation.
If your instance uses the Orgs feature for multi-tenancy, you can manage
users within each Org independently.

=== Groups
Organize users into groups to control what they can see and do in ThoughtSpot.
Groups determine privileges — such as the ability to download data, manage
other users, or upload data — as well as data access through Row-Level Security
(RLS) rules.

=== Orgs
If your ThoughtSpot instance is configured for multi-tenancy, the *Orgs* section
lets you create and manage Orgs — independent, tenant-specific environments
that share the same ThoughtSpot cluster but keep their users and data separate.
Each Org behaves like its own ThoughtSpot instance.

=== Security
Configure authentication settings for your ThoughtSpot instance.
This includes setting up Single Sign-On (SSO) via SAML or OIDC, managing
trusted authentication for embedded deployments, and controlling session
policies such as idle timeout and maximum session validity.

=== Data Management
Manage data connections, uploaded data, and data platform settings.
Administrators can review the status of data sources connected to ThoughtSpot,
manage scheduled data loads, and configure data platform behaviors.

=== Style Customization
Customize the visual appearance of your ThoughtSpot instance to match your
organization's branding.
You can upload a custom logo, change the application color palette, and adjust
chart and table display defaults.

Style customization settings are also available in the *Develop* >
*Customizations* > *Styles* section for embedded deployments.

=== Help Customization
Add custom links to the ThoughtSpot *Help* menu so users can access your
internal resources, support portals, or training materials directly from
within ThoughtSpot.

=== Application Settings
Review and configure instance-level settings, including feature flag
overrides, default behaviors, and environment-specific options that apply
across all users on your ThoughtSpot instance.

== Note on access and Orgs
The sections available in your Admin page depend on your administrator role
and your instance configuration.

* Cluster administrators on a multi-tenant instance see all Orgs and
cross-Org settings.
* Org administrators see settings scoped to their assigned Org only.

If a section described here is not visible in your instance, contact your
ThoughtSpot cluster administrator.
