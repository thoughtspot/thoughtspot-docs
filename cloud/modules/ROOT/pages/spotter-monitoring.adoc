ThoughtSpot administrators can monitor how users interact with Spotter — including
usage trends and individual chat sessions — from the Spotter monitoring panel in the
Admin portal.

Use Spotter monitoring to understand adoption, review chat quality, and identify
where users get stuck.

== Prerequisites

* You must have the *Can administer ThoughtSpot* or *Can administer Org* privilege.
* Spotter must be enabled on your instance.
* Chat history must be enabled.
+
[NOTE]
====
If chat history is turned off, Spotter monitoring shows usage metrics but does not
show individual chats.
====

== Open Spotter monitoring

. Navigate to *Admin* > *ThoughtSpot AI*.
. Select *Spotter monitoring*.

== View Spotter usage metrics

The *Usage* tab shows aggregate metrics for your instance or Org.

[cols="1,2",options="header"]
|===
|Metric |Description

|Total chats
|The number of Spotter chat sessions started in the selected time range.

|Active users
|The number of distinct users who started at least one chat in the selected time range.

|Questions asked
|The total number of questions submitted to Spotter across all sessions.

|Successful answers
|The number of questions that returned a visualization or data result.

|Sessions by surface
|Breakdown of chat sessions by surface: homepage, Liveboard, or Search Answers.
|===

Use the date range selector to filter metrics by day, week, or custom range.

== Review all chats

The *Chats* tab lists individual Spotter chat sessions.
Each row shows the user, the surface where the chat happened, the date, and the
number of questions in the session.

To review a session:

. Select a row in the *Chats* table.
. The chat transcript opens in a side panel, showing each question and Spotter's response.
. Review the questions asked and the answers returned.

You can filter the list by:

* User
* Surface (homepage, Liveboard, Search Answers)
* Date range

== Monitoring when chat history is turned off

If chat history is turned off on your instance:

* The *Usage* tab continues to show aggregate metrics.
* The *Chats* tab is not available and individual sessions cannot be reviewed.
* Users do not see their previous chats when they open Spotter.

To review individual chats, turn chat history on from *Admin* > *ThoughtSpot AI* >
*Chat history*.
