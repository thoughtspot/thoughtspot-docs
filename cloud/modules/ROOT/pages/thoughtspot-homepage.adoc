== New home page

On the new home page, you can explore insights, search and access your library of Answers and Liveboards, and more. You can now choose between focused and modular home page options.

// SOURCE: SCAL-309500 (QA sign-off comment, 2026-10-08); SRE KT https://thoughtspot.atlassian.net/wiki/spaces/SRE/pages/4805296129
// TODO: verify with engineering — focused home page is the default for new ThoughtSpot Cloud instances from 26.11.0.cl; existing instances keep their current setting after upgrade.
New ThoughtSpot Cloud instances use the focused home page by default. Administrators can manage the home page version for all Orgs, or for each Org. To change your home page experience, contact your administrator.

== Enabling the focused or modular home page for administrators

// SOURCE: PRD Focused Homepage V4 (Admin Settings), https://docs.google.com/document/d/1XRwaY2nbZJUrjcMUQyCofkpj_SzEp2BLI0Zg65NHDxk
The home page experience setting is available at the All Orgs level and at the Org level. An administrator with access to All Orgs must first select *Focused* for all Orgs. After that, Org administrators can switch their Org back to *Modular*.

To enable your desired home page:

// TODO: verify with engineering — menu path. These steps say Customization > App Experience. SCAL-309500 QA comment and SRE KT say "Home Page & App Experience". The Admin settings table on this page lists "Home Page & Discovery".
. Go to *Admin settings*.
. Select *All Orgs*, or select the Org you want to configure.
. Go to *Customization*.
. Select *App Experience*.
. Go to *Homepage experience* and click *Edit*.
. Select *Focused* or *Modular* and click *Save*.

// SOURCE: dev/scaligent PR #69390 (SCAL-336944), string adminSection.homepageExperience.errorModal.body
If Spotter is disabled for your instance, you cannot select *Focused*. ThoughtSpot shows the message *Experience cannot be changed to "Focused" because Spotter is disabled in this instance*. To enable Spotter, contact ThoughtSpot Support.

== Focused home page
ThoughtSpot has a new focused home page experience. The focused home page delivers a streamlined, contemporary experience for users that highlights the Spotter experience.
It includes shortcuts to allow you to do a *Quick search*, *Deep analysis*, or *Know your data*. It also includes a list of *Recents* and your *Watchlist* KPIs.

// SOURCE: SRE KT https://thoughtspot.atlassian.net/wiki/spaces/SRE/pages/4805296129; PRD Focused Homepage V4
The focused home page requires Spotter. If Spotter is not enabled for your instance, ThoughtSpot shows the modular home page.

== New navigation

The new global navigation organizes ThoughtSpot into different contextual sections. Each one is designed for a common type of ThoughtSpot user. You navigate to each option using the tabs in the left hand menu.

.*Insights*
The *Insights* tab is designed for the business user.

image::insights-tab.png[Insights tab]

.*Data workspace*
The *Data workspace* tab is designed for the data engineer.

image::data-workspace-tab.png[Data workspace tab]

.*Develop*
The *Develop* tab is designed for developers.

image::develop-tab.png[Develop tab]

.*Admin settings*
The *Admin settings* tab is designed for administrators.

== Command palette

You can now access anything in ThoughtSpot from a single keystroke. The command palette (kbd:[`Cmd`] + kbd:[`K`] on Mac / kbd:[`Ctrl`] + kbd:[`K`] on Windows and Linux) is a global command center that unifies navigation, search, and actions across the ThoughtSpot platform. Instead of switching between menus, list pages, and contextual controls, you can find content, trigger workflows, and navigate to any part of the product — all from one place.

With the command palette, you can:

--
* Search across Liveboards, Answers, Models, and more in one place.
* Launch a new Answer, Liveboard, or Spotter chat.
* Jump to any section of ThoughtSpot directly, from Home to Admin settings.
* Type your data question and send it straight to Spotter.
* Press forward slash (/) to filter your search by Liveboards, Answers, Admin Settings, Create, Spotter, Models, Tables, and Collections.
*  Search results highlight matching terms for faster scanning, and visuals make it easier to understand what's happening as you search.
