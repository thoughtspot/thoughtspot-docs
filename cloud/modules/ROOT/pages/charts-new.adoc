The new chart settings experience provides a more intuitive layout organized by chart objects like chart type, layout, column, axis, data label, tooltips, legends, display, and query, where properties for a component are listed with the component.

You no longer have to configure the same settings multiple times, because commonly used properties are inherited across similar chart elements. For example, if you apply number formatting to one column, it will be applied to multiple columns, though you can change it later if you want.

By default, chart settings load in _basic_ mode, which provides the most common settings. However, you can change to _advanced_ mode in some settings panels to display additional settings. The _advanced_ setting is saved individually with the setting, so each time you return to the new chart settings experience, it will remember your setting from the last time you used it. Enabling _advanced_ mode in one setting panel, enables it for all settings panels which have an _advanced_ mode.

== Settings panels

The following buttons on the right side of your chart allow you to control various setting of your chart. Which panels are available depends on the chart you selected.

[cols="50%,50%", grid=none, frame=none]
|====================
a| In the _Type_ panel, you select the type of chart you want to use.

|====================

[#layout]
=== Layout
[cols="50%,50%", grid=none, frame=none]
|====================
a| In the _Layout_ panel, you see the x and y axes of your chart.

Depending on the chart, you also can slice with color or not visualize a column.

a| [.bordered]
image::chart-layout-new.png[]
|====================


[#column]
=== Column
[cols="50%,50%", grid=none, frame=none]
|====================
a| In the _Column_ panel, you can rename the columns, change the sort order, and format the numeric, percentage and currency of the measure.  You can also change the color used in the visualization, and set up conditional formatting.

If the _advanced_ mode is enabled, you can change the aggregation used.

a| [.bordered]
image::chart-column-new.png[]
|====================

[#axis]
=== Axis
[cols="50%,50%", grid=none, frame=none]
|====================
a| In the _Axis_ panel, you can rename the axes, change the number format of the value label, and the position of the Y-axis.

If the _advanced_ mode is enabled, you can change the format, size and color of the text. format the numeric, percentage and currency of the measure.  You can also change the range of the Y-axis, and display axis lines and intervals.

a| [.bordered]
image::chart-axis-new.png[]
|====================

[#display]
=== Display
[cols="50%,50%", grid=none, frame=none]
|====================
a| In the _Display_ panel, you have various display options for your chart, including fitting it to the screen, automatically setting bar widths, and maximum data points. You can also zoom into a specific area of the chart.

If the _advanced_ mode is enabled, you can change settings like chart and plotted area background and border colors.

a| [.bordered]
image::chart-display-new.png[]

[#query]
=== Query
[cols="50%,50%", grid=none, frame=none]
|====================
a| In the _Query_ panel, you can see the details of the query used to generate your chart.

You can click *Query visualizer* to see how ThoughtSpot generated your visualization by displaying the queries, tables, join paths, and fields used.

You can also click *Query SQL* to view the exact SQL query used to generate the chart.
a| [.bordered]
image::chart-query-new.png[]
|====================
