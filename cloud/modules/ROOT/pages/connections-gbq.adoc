== Connecting ThoughtSpot to Google Cloud Services using Private Google Access

Private Google Access allows ThoughtSpot Cloud environments to connect securely to Google Cloud APIs and services (for example, BigQuery, Cloud Storage) without requiring public IP addresses. When enabled, VMs and services with only private IPs in a VPC subnet can reach Google APIs internally over Google’s network.

This ensures all data traffic between ThoughtSpot and Google Cloud services remains private, secure, and compliant.

You can configure Private Google Access connectivity to Google BigQuery following link:https://cloud.google.com/vpc/docs/private-google-access[instructions,window=_blank].

If you need to enforce link:https://cloud.google.com/vpc-service-controls/docs/private-connectivity[VPC Service Controls] to restrict access to the specific VPC where your ThoughtSpot Cloud instance is deployed, reach out to {support-url}.
