Waterfall charts show how an initial value increases or decreases through a series of intermediate positive and negative values, leading to a final total. They are commonly used for financial analysis, such as visualizing profit and loss statements, revenue breakdowns, and cash flow analysis.

== New capabilities

The Muze-powered Waterfall chart introduces the following capabilities not available in the classic version:

// SOURCE: Jira SCAL-299441 — New Capabilities section

* *New color configuration logic for increments and decrements* — Configure distinct colors for positive (increment) and negative (decrement) bars to improve visual clarity.
* *New axis configuration logic for multivariates and grouped axis* — Build complex multivariate Waterfall charts with improved axis handling.
* *Faceting and Trellis chart modes* — Partition Waterfall charts into faceted grids or trellis small multiples for multidimensional analysis.
* *Configurable total and ending bars* — Designate specific bars as total or ending values, which are rendered differently from intermediate increment and decrement bars.

== Behavior changes

When migrating from the classic Waterfall chart to the Muze-powered version, note the following changes:

// SOURCE: Jira SCAL-299441 — Existing Feature Gaps / Behavior Changes section

* *Classic Bar width settings unavailable* — Group padding and bar padding settings are not available in the new Waterfall chart. This is consistent with other Muze-powered charts.
* *Connector lines* — Connector lines between bars behave differently in the new renderer.
* *Custom font support* — Custom font settings apply differently compared to classic charts.
* *Null and empty handling* — Null and empty values are handled differently in the new renderer.
* *Non-visualized fields in tooltip* — Adding non-visualized fields to tooltips is not supported in the new Waterfall chart.

== Configure a Waterfall chart

To create a Waterfall chart:

. Start a new search or open an existing Answer.
. In the chart selector panel, select *Waterfall* from the *New* section.
. Add at least one measure and one attribute to your query.
. To configure total bars, open the chart settings and specify which values should render as totals.
. Customize colors for increments and decrements in the chart settings panel.
