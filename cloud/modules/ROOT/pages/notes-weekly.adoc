|====================
|[.badge.badge-fix-relnotes]#Fix#| Liveboard excel download feature now supports XLSX files with unicode characters in visualization titles.

[cols="10%,90%", grid=none, frame=none]
|====================
|[.badge.badge-fix-relnotes]#Fix#| Auto mode is now preserved as the Spotter data source across pages and new conversations, ensuring a consistent user experience.

|====================

[cols="10%,90%", grid=none, frame=none]
|====================
|[.badge.badge-fix-relnotes]#Fix#| Liveboard export APIs did not correctly apply `filter_rules` embedded in tokens generated by `/api/rest/2.0/auth/token/custom`, and would return blank pdfs, or visualizations not showing any data. [cols="10%,90%", grid=none, frame=none]

These calls have now been updated to work correctly thus restoring reliable access to the security settings.
|====================
