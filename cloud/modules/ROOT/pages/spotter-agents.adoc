Spotter agents are a unified suite of AI agents built on the ThoughtSpot Agentic Analytics Platform. Each agent is designed for a different role in your organization — from data engineers to analysts to developers — so that every team can move faster, work smarter, and spend less time on manual analytics tasks.

== Spotter

Spotter is ThoughtSpot's flagship conversational analytics agent. Ask questions in plain English and get instant, trusted answers backed by your data. Spotter 3 goes beyond traditional BI by blending structured data (your databases and data warehouses) with unstructured data sources to give you the full picture behind every business question.

For more information, see xref:spotter.adoc[].

== SpotterModel [.badge.badge-early-access]#Early Access#

Use SpotterModel to generate comprehensive, optimized Models ready to use in your analysis. SpotterModel automates table selection, join creation, and column selection, while allowing you to review and customize each step.

For more information, see xref:spotter-model-create.adoc[].


== SpotterViz [.badge.badge-early-access]#Early Access#

SpotterViz can autonomously create Liveboards based on your prompts, populating them with relevant visualizations and KPIs. In response to your query, ThoughtSpot evaluates available data sources, creates analysis, and lays out the information for you. After creating a Liveboard, you can enter more prompts in SpotterViz at any time to revise and refine it. You can also give feedback by using the thumbs up and thumbs down buttons.

For more information, see xref:spotter-viz.adoc[].

== SpotterCode

SpotterCode is an AI coding assistant built for ThoughtSpot developers. Describe what you want to build in plain language and SpotterCode generates the correct embed code instantly — no more hunting through API references or SDK docs. Spend less time on syntax and more time shipping features.

For more information, see https://developers.thoughtspot.com/docs/SpotterCode[SpotterCode^].
