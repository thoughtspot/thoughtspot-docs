The *Data* workspace is where data professionals connect, prepare, and
manage the data that powers analytics in ThoughtSpot.
If you are an analyst, data engineer, or BI developer, this is where you
work with data sources, build models, and publish governed datasets that
your organization can search and explore in the *Insights* workspace.

The left navigation panel gives you quick access to everything you need.

== What you can do from the Data workspace

=== Connections
*Connections* is where you link ThoughtSpot to your external data sources,
including cloud data warehouses such as Snowflake, Google BigQuery, Amazon Redshift,
and Databricks, as well as other supported databases and file sources.

From the Connections page, you can:

* Add a new connection to an external data warehouse
* Edit or remap existing connections
* Delete connections that are no longer needed
* Apply or remove tags on connections for easier organization

Each connection you create becomes the foundation for the tables, models,
and views you build in ThoughtSpot.

=== Data objects
*Data Objects* lists all the data sources available to you in ThoughtSpot.
Data objects come in three types:

[horizontal]
Tables:: Raw tables imported or linked from a connected data source.
Models:: The primary data object for search and analytics in ThoughtSpot.
Models define the relationships, column names, synonyms, and row-level
security rules that make data accessible and trustworthy for business users.
Views:: Saved SQL-based definitions that produce a virtual table.
SQL views fall under the Views category.

Most users work primarily with Models and Views.
Models are the most powerful and commonly used data source for searching in
ThoughtSpot.

=== Analyst Studio
*Analyst Studio* is ThoughtSpot's intelligent data preparation and advanced
analytics environment.
It bridges the gap between raw data and governed insights by giving data
teams a versatile toolkit (SQL, Python, R, and spreadsheets)
to explore, transform, and prepare data before it reaches end users.

Analyst Studio is organized around two core concepts:

[horizontal]
Collections:: Personal or shared workspaces that group your analytical work.
Every Report you create is added to a Collection automatically.
Reports:: The primary analytical unit in Analyst Studio.
Open or create a Report to start querying, transforming, or visualizing data
using SQL, Python, R, or spreadsheet-style analysis.

Analyst Studio is designed for data analysts, BI professionals, and data
engineers who need to prepare AI-ready datasets, manage cloud costs, and
collaborate across technical and business teams, all within the same
ThoughtSpot platform.

== Who uses the Data workspace?
The Data workspace is primarily used by:

* *Data engineers*: connecting data warehouses, managing tables, and
maintaining data pipelines
* *Data analysts and BI developers*: building models, writing SQL and
Python transformations in Analyst Studio, and publishing datasets
* *ThoughtSpot administrators*: overseeing connections and data object
governance

Business users and analysts who consume data do not typically need to visit
the Data workspace.
Their entry point is the *Insights* workspace, where they search and explore
the governed data that the Data workspace produces.

== Note on access
Your access to sections of the Data workspace depends on the privileges
assigned to your user group by your ThoughtSpot administrator.
If a section described here is not visible in your instance, contact your
administrator to request the appropriate data management privileges.

[#sort]
=== Sort data sources

You can sort the data sources that display on the home page of the Data workspace in the following ways:

* *Alphabetically by author*: You can sort by author alphabetically, either ascending or descending.
Select *Author*, above the list of recently modified data sources.
To see ascending order, select *Author* again.
* *Alphabetically by name*: You can sort by object name alphabetically, either ascending or descending.
Select *Name*, above the list of recently viewed data sources.
To see ascending order, select *Name* again.
* *By how recently anyone modified the object*: You can sort by how recently anyone modified the object, either ascending or descending.
Select *Last modified*, above the list of recently modified data sources.
To see ascending order, select *Last modified* again.

To see more objects, scroll down to the bottom of the page and select *Next*.
ThoughtSpot displays 20 objects on each page.

These changes do not persist across sessions.
If you sign out and sign back in, the view returns to the default.

Your connections appear under *Connections* in the side navigation bar of the Data workspace.
From the *Connections* page, you can add, edit, remap, and delete connections, and apply or remove tags.

To connect to your data in an external data warehouse, see xref:connections.adoc[Data connections].

=== Add a connection
To *add* a connection, select the icon for the type of connection you would like to add, such as Snowflake or Amazon Redshift. If you do not see your data warehouse, and it is one of ThoughtSpot's xref:connections.adoc[supported data warehouses], select *Others*.

You can also create a new connection by selecting *+ Create new* in the left navigation bar, then selecting *Connection*.

ifdef::spotter[]
IMPORTANT: Choosing to create a connection using either of these methods will *not* guide you through modeling your data, coaching {form-factor} or using {form-factor} to chat with your data, as described in xref:connections.adoc[Adding data sources in {form-factor}].
endif::[]

=== Edit, remap, or delete a connection

To *edit*, *remap*, or *delete* a connection, select the *More* menu image:icon-more-10px.png[more menu icon] for the connection, and select the action you would like to take.

=== Bulk actions
To *bulk delete* or *apply tags in bulk*, follow these steps:

. Select the empty boxes next to the object names, or, if you would like to perform a bulk action on all 20 connections on the page, select the check box at the top of the list.

. At the top of the list of connections, several buttons appear. You can delete the connections or apply or remove xref:tags.adoc[tags].

=== Filter connections

Use the filters and the search bar at the top of the list of connections to find the connection you are interested in. You can filter in the following ways:

* By *tag*
* By *author*

You can also use the search bar to find a specific connection, if you know its name.
