To view the current status of ThoughtSpot Cloud services, go to the ThoughtSpot Status page at: https://status.thoughtspot.cloud/[https://status.thoughtspot.cloud/^]. Here you can find information and updates about service interruptions in different geographical regions, as well as a list of past incidents.

You also have the option to subscribe to updates through email, text, Slack, Microsoft Teams, and Atom or RSS feeds.

If you are experiencing problems and do not see a notice posted, please contact {support-url} for assistance.

=== Status information

The ThoughtSpot Status page displays the status of the following ThoughtSpot services:

* Spotter
* MCP Server
* Analyst Studio
* ThoughtSpot Sync
* Other Services
