The stacked bar chart is similar to the xref:chart-bar.adoc[bar chart], but with one major difference.
It includes a legend, which divides each bar into additional sections by color. Note that you can only use an attribute to slice with color.

Stacked bar charts are typically used when you want to compare aggregated data and the data that it includes together.
Select a configurable axis chip (any axis chip with a *>*) to show Detail Labels (summaries for each section of each bar) and Total Labels (show the sum of the stacks for each bar).

[.bordered]
image::charts-stacked-bar-new.png[Stacked bar chart with labels]

== Supported configurations
* *Single Measure Stacked*: Sliced by a single attribute using color.
* *Multiple Measures Stacked*: Measures are stacked on top of each other, with no slicing by color.
* *Multivariate Stacked*: Each measure forms a separate stacked chart

== Automatic transformations (for stacking)
* *Single measure, Slice by color present*: Automatically stack the slices of the measure and apply a stack transform.
* *Multiple Measures, No Slice by Color*: Move all measures into a shared axis (Measure Values construct), auto-apply stack transform on all measures.
* *Multiple measures, slice by color present*: Convert to a multivariate chart where each measure is sliced by the attribute, and a stack transform is applied to each individual layer.


== Limitations

* Shared-axis configuration is not supported.
* Dual-axis configuration is not supported.
