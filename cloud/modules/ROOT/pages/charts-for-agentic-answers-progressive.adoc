Progressive charting delivers a base chart quickly and then enhances it in the background.
This ensures you can start analyzing data within seconds, while richer styling and formatting are applied automatically.

== How progressive charting works

Progressive charting operates in two phases:

1. *Base chart rendering* (3–5 seconds) — The charting engine generates a functional, interactive chart with correct axes, data series, and basic formatting. The chart is immediately displayed.
2. *Background enhancement* — While you interact with the base chart, the system applies additional enhancements in the background:
** Refined color schemes and styling
** Data labels and annotations
** Legend positioning and formatting
** Axis formatting improvements
** Additional interactive elements

Once the enhancements are complete, they merge seamlessly into the base chart. The transition is smooth and does not require a page refresh or manual action.

== What to expect

=== Phase 1: Base chart (0–5 seconds)

When you receive a non-token answer with chartable data:

* A loading indicator may appear briefly
* The base chart renders with:
** Correct chart type (for example, line, bar)
** Axes and scales
** Data series
** Basic legend

The base chart is fully interactive. You can hover, pan, zoom, and toggle series immediately.

=== Phase 2: Enhancement (5–15 seconds)

While you work with the base chart, the system:

* Applies AI-recommended styling
* Adds data labels if appropriate
* Refines axis formatting
* Adjusts colors and visual encoding

[NOTE]
====
The exact timing depends on the complexity of the data and the chart.
Simple charts (for example, a single-series line chart) may complete enhancements in a few seconds.
Complex charts with multiple series, annotations, or custom formatting may take longer.
====

=== Phase 3: Final chart

When enhancements complete:

* The chart updates visually with the improved formatting
* No manual refresh is required
* All interactivity is preserved

== Interacting during progressive loading

You do not need to wait for enhancements to finish before using the chart:

* Hover over data points to see values
* Toggle series on and off using the legend
* Pan and zoom to explore data
* Submit follow-up xref:charts-for-agentic-answers-nl-editing.adoc[natural-language chart editing] requests

Any natural-language editing commands submitted during the enhancement phase are applied to the final chart once enhancements complete.

== When progressive charting applies

Progressive charting is automatically enabled for all agentic charts.
There is no user setting to enable or disable it.

Progressive charting is most beneficial when:

* Network latency is high
* Data sets are large or complex
* Multiple data series require individual styling

== Performance considerations

* The base chart is designed to be *functionally complete* — you can make decisions from it immediately.
* Background enhancements focus on *visual polish* — they do not change the underlying data, chart type, or axis scales.
* If you submit a xref:charts-for-agentic-answers-nl-editing.adoc[natural-language editing] command before enhancements complete, the system prioritizes your command and applies it after the current enhancement cycle finishes.

== Limitations

* Progressive charting applies to agentic charts only. Standard token-based charts use the existing rendering pipeline.
* The base chart may appear with minimal styling (for example, default colors, no data labels) before enhancements complete.
* In rare cases, if a natural-language command conflicts with an in-progress enhancement, the command takes precedence and the enhancement is reapplied.
