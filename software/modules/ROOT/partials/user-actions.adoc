[#tracking-answer-downloads]
== Tracking Answer downloads

The `data_export` user action is recorded for Liveboard exports and Answer chart image (PNG) downloads only.

Table downloads from an Answer (CSV, XLSX, PDF) are not tagged with a `user_action` value and do not appear in the TS: BI Server worksheet when you filter by this action.

To track Answer table downloads, filter the TS: BI Server worksheet on URL contains `data/answerbook/export`. Each row represents one Answer download and includes the user, timestamp, response size, and status.

[NOTE]
====
The Answer name and GUID columns are empty for Answer download rows.
====

Security audit logs do not cover downloads or exports. They cover metadata, group, and role changes only.
