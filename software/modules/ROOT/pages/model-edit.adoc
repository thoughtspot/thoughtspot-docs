NOTE: Worksheets are now referred to as Models.


Anyone with the proper permissions can edit a Model. If you created a Model, or you have edit permissions on it, you can make changes such as adding sources and columns, adding or editing formulas, changing relationships, and changing column names.
You can also rename a Model or change its description.

Alternatively, you can export a Model as a flat file in xref:tml-models.adoc[TML], ThoughtSpot's Modeling Language, edit the file, and import the file to the same or another cluster.
See xref:scriptability.adoc[Migrate or restore objects].

== Editing a Model

To edit a Model:

. Select *Data* on the top navigation bar.
. Select the name of the Model you want to edit.
. Select the *Edit* button in the upper-right side of the screen.
. Make your changes to the Model.
. Select *Save changes*.

== Renaming a Model or table

You can change a Model or table name from the ThoughtSpot application.

To change the name of a Model or table:

. Select *Data*, on the top navigation bar.
. Find the Model or table you want to rename and select its name.
. Select the current name, and enter a new name.

[#copy]
== Making a copy of a Model

You can create a copy of a Model, if you would like to make edits without changing the original Model.
When saving, you can type in a different name for your copy.

To make a copy of a Model:

. Select *Data*, on the top navigation bar.
. On the Model list page, select the Model you would like to edit a copy of.
. Open the *More* menu icon image:icon-more-10px.png[more options menu icon] and select *Make a copy*.

+
The *Make a copy* dialog appears.

. Change the name and description, as needed, and select *Save*.
+
When you navigate back to the *Data* page, your new Model name appears in the list.
