The new line column chart combines the column and line charts.
Your search needs at least one attribute and two measures to be represented as a line column chart.


== Understand line column charts


Line column charts display multiple measures as a column chart and the multiple others as a line chart.
Each of these measures has its own y-axis.


[.bordered]
image::line_column_chart_new_example.png[New line column chart example]


== New feature
Ability to choose which measure is visualized as a bar and which is visualized as a line.


[.bordered]
image::multiple-line-col-new.png[Line column chart with n measures in lines, and n measures in columns]




== Limitations


* Dual-axis or multivariate axis transitions are not supported.
* Slice by color is not supported for line or column layers.
* Adding a third axis entity is not supported.
* Removing or emptying either of the two shared axes is not supported.
* Using an internal dual-axis configuration within either of the main shared axes is not supported.
