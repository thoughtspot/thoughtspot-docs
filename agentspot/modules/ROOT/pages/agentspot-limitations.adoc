== AgentSpot rights of use

Standalone AgentSpot customers receive access to ThoughtSpot Pro Edition solely to configure, administer, and support their use of AgentSpot.  This access is provided for AgentSpot-related setup and management only.  It does not include general use of ThoughtSpot Analytics or ThoughtSpot Embedded.

Customers that want to use ThoughtSpot for broader analytics use cases must purchase a separate subscription to ThoughtSpot Analytics or ThoughtSpot Embedded.

== Permitted use
AgentSpot customers may use ThoughtSpot Pro Edition to:

* Set up and manage user access and provisioning
* Configure one or more data models for use with AgentSpot
* Configure Spotter for use through AgentSpot only
* Perform other administrative activities necessary to enable and manage AgentSpot

== Restricted use
Unless separately purchased, AgentSpot customers may not use ThoughtSpot Pro Edition to:

* Create, author, or publish any Answers or Liveboards
* Use Spotter directly outside of AgentSpot
* Use Spotter agents outside of AgentSpot
* Schedule alerts
* Use the ThoughtSpot Embedded API or SDK
* Use more than one ThoughtSpot Org
* Use ThoughtSpot for standalone business intelligence, reporting, analytics or embedded analytics use cases

== Additional subscription requirement
Any use of ThoughtSpot beyond the AgentSpot-related configuration and administration described above requires a separate ThoughtSpot subscription. Customers should contact ThoughtSpot if they want to use ThoughtSpot Analytics, ThoughtSpot Embedded, or other ThoughtSpot capabilities outside of AgentSpot.

== Do credits

Usage in AgentSpot is measured by Data to Outcome (Do) credits.  A credit is consumed anytime a user starts a new conversation with an agent, a Workflow is run on a users behalf or an agentic application is loaded.  Dos are measured on a weekly basis, any single conversation, workflow or App load that remains active beyond a continuous 24-hour period will consume one additional Do for each subsequent 24-hour period, or portion thereof, during which such conversation or workflow remains active.

== Reasonable use

Unlimited use of AgentSpot includes foreseeable uses such as long conversations and complex workflows. However, heavy programmatic query commands or performance stress-testing and probing is not included in the subscription. ThoughtSpot reserves the right to limit use above Reasonable Use.

Reasonable Use is monthly usage that does not exceed 1M input tokens and 50k output tokens from language models in the account per month.

If use beyond Reasonable Use is found, ThoughtSpot will provide you with written notice that includes a description of the usage patterns at issue, and a time in which you may purchase additional Data to Output Credits. If neither action is taken, ThoughtSpot reserves the right to suspend or terminate use until the issue is resolved.
