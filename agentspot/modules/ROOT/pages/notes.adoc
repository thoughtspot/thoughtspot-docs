== August 4, 2026 (based on what's new in agentspot august 4th)

=== New features

"Get started" onboarding card on the home page (Beta)::
A new "Get started" card appears on the home page the first time you log in, and can be revisited anytime from the profile menu. It includes an intro video and quick-start prompts that jump straight into building an agent, workflow, or data app with a prefilled starting point, making it faster and easier for new users to begin building without hunting for onboarding materials.

=== Improvements

Workflow run visibility in regional environments::
Workflow run details, graphs, and artifacts now load correctly in regional deployments instead of showing a blank screen. A clear error message appears if something does go wrong, so teams working in regional environments can trust and act on workflow run information.

Like counts on "Most used by your Org" cards::
Agent cards in the "Most used by your Org" highlight strip now show like counts and the heart icon, matching the rest of the Agents page and giving users consistent signals to help them find popular agents.

Cleaner Tools panel in the agent builder::
The agent builder's Tools panel no longer shows raw internal tool names. Tools are now grouped under clear, recognizable categories, making it easier to find what you need when building an agent with connectors or file tools.

Claude Opus 4.7 now available in EU environments::
Claude Opus 4.7 is now available for EU customers. Requests to use the model from EU environments no longer fail.

More reliable connector login refreshes::
Refreshed logins for connected accounts such as Google Workspace or Slack are now reliably saved instead of occasionally being discarded, reducing unexpected disconnections for connected integrations.

Clearer credits and pricing visibility::
Onboarding now shows how many agents, workflows, and apps remain on your Free plan. The admin credit activity list supports loading more results, tenants that run out of credits can request a credit loan from an admin, and wording throughout credit usage screens is clearer.

Do Credits page and balances::
The Do Credits usage page no longer crashes for tenants that use data apps. Weekly credit balances now update correctly after a plan upgrade instead of staying stuck at the old amount, giving tenants accurate, reliable visibility into their credit usage.

=== Bug fixes

* Fixed a rare background error that could occur when quickly navigating away after liking an agent.
* Fixed an issue where new EU tenant provisioning requests failed with a not-found error.
* Fixed an issue where production EU tenant admin traffic was routed to US identity systems instead of EU ones.

== July 31, 2026 (from Engineer Agents)

=== New features and improvements

Data app previews run on real data::
Preview now runs real fetches and code before you publish, so you can catch issues before your app goes live.

Clearer connector status and management for agents::
You can now see at a glance which connectors are live, broken, or need reconnecting, making it easier to manage agent connections.

Improved app sharing onboarding::
A popover now guides you through sharing your app right after your first publish.

Redesigned home page for agents, apps, and workflows::
The home page has been updated with drag-to-reorder cards, colorful app tiles, and a cleaner workflow list.

Agents can connect to org-wide Slack channels::
Internal shared Slack channels are now supported for agent bindings.

Do Credits billing improvements::
Several fixes have been made to credit loans, usage tracking, and charge and credit indicators ahead of launch.

AI usage costs now internal-only::
AI cost breakdowns have been moved to ThoughtSpot's internal portal, split by activity type.

Reorganized user menu::
The user menu has clearer sections, the "Learning Center" has been renamed, and a new Community link has been added.

=== Bug fixes

* Fixed an issue where the browser back button did not navigate correctly.
* Improved error messages for data apps to show specific errors and reconnect options instead of generic failures.
* Fixed an issue where admins with older Slack connections could not see their channels.
* Fixed an issue with Google Workspace data app connections not setting up correctly.
* Fixed an issue where likes on shared agents and apps did not appear on the home page.
* Fixed an issue where non-owners were redirected to the wrong page when clicking edit links.
