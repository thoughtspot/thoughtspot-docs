AgentSpot is a managed platform for building and using AI agents on top of your organization's data, tools, and processes — without writing code.

== In one paragraph

AgentSpot lets your teams create *agents* (focused assistants that answer questions or perform tasks) and *workflows* (multi-step automations that chain agents and actions together). Agents and workflows run on data your admin has connected, use models your admin has approved, and operate under controls your organization sets. Anyone in your organization with the right role can build them; anyone with access can use them.

== What you can build

A few representative examples:

* *Pipeline assistant* — answers questions about open opportunities, forecasts, and historical close rates, scoped to a region.
* *Lead triage* — when a new lead arrives, an agent scores it and routes it to the right owner.
* *Weekly KPI digest* — a workflow gathers the week's numbers, an agent drafts a narrative, the result is posted to a Slack channel every Monday.
* *Customer-response drafter* — given a support ticket, an agent drafts a reply grounded in your knowledge base, ready for a human to edit and send.
* *Document Q&A* — upload a long policy document, ask questions, get cited answers.

== Who AgentSpot is for

* *Administrators* configure the platform — identity, data sources, model providers, governance.
* *Agent builders* (typically analysts, ops leads, PMs, customer success) create agents and workflows for their teams. No code required.
* *End users* use the agents that builders have published.

Most people will be end users. A small number of people in each team will be builders. A handful of people per organization will be admins.

== How AgentSpot fits with ThoughtSpot

AgentSpot is part of the ThoughtSpot platform. It runs alongside your existing ThoughtSpot tenant on the same identity, governance, and data connections. ThoughtSpot Models and Worksheets are first-class data sources for agents, so analytics work you've already done in ThoughtSpot can power agents on day one.

== What AgentSpot is not

* It is not a general-purpose chatbot. Each agent is narrow and scoped to a specific job.
* It is not a code IDE. Builders work in a no-code editor; developers extend the platform separately.
* It is not an analytics tool. Use ThoughtSpot for ad-hoc exploration; use AgentSpot when the same question gets asked repeatedly, or when an answer needs to trigger an action.
