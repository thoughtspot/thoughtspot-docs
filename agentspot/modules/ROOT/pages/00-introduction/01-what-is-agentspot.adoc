= What is AgentSpot
:last_updated: June 17, 2026
:linkattrs:
:experimental:
:page-aliases:

[.lead]
AgentSpot is a managed platform for building and using AI agents on top of your organization's data, tools, and processes — without writing code.

== In one paragraph

AgentSpot lets your teams create *agents* (focused assistants that answer questions or perform tasks) and *workflows* (multi-step automations that chain agents and actions together). Agents are enabled by your admin. Agents and workflows run on data you have connected, use models your admin has approved, and operate under controls your organization sets. Anyone in your organization with the right role can build them; anyone with access can use them.

== What you can build

A few representative examples:

* *Pipeline assistant* — answers questions about open opportunities, forecasts, and historical close rates, scoped to a region.
* *Lead triage* — when a new lead arrives, an agent scores it and routes it to the right owner.
* *Weekly KPI digest* — a workflow gathers the week's numbers, an agent drafts a narrative, the result is posted to a Slack channel every Monday.
* *Customer-response drafter* — given a support ticket, an agent drafts a reply grounded in your knowledge base, ready for a human to edit and send.
* *Document Q&A* — upload a long policy document, ask questions, get cited answers.

== Who AgentSpot is for

* *Administrators* configure the platform — identity, data sources, governance.
* *End users* can create agents and workflows, and share them with their teammates. They can use any agent they created as well as any agent that has been shared with them. No code required.

Most people will be end users. A handful of people per organization will be admins.

== How AgentSpot fits with ThoughtSpot

AgentSpot is part of the ThoughtSpot platform. It runs alongside your existing ThoughtSpot tenant on the same identity, governance, and data connections. ThoughtSpot Models are first-class data sources for agents, so analytics work you've already done in ThoughtSpot can power agents from day one.

AgentSpot uses Spotter 3 to help you respond to any data-related questions on AI-enabled ThoughtSpot models.

== What AgentSpot is not

* It is not a general-purpose chatbot. Each agent is narrow and scoped to a specific job.
* It is not a code IDE. Agent creators work in a no-code editor.
* It is not an analytics tool. Use ThoughtSpot for ad-hoc exploration; use AgentSpot to tie facts coming from ThoughtSpot models to a purpose-built agent and data coming from other connectors, or when an answer needs to trigger an action.
