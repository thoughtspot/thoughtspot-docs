Welcome to the AgentSpot Administrator's Guide. This document outlines the essential steps for setting up your environment, managing users, and configuring connectors to ensure your team is ready for launch.

== Getting Started with the Admin Center
The AgentSpot Admin Center is your central hub for account configuration, governance, and monitoring.

To access the Admin Center:
1. Log in to your Fotspot account.
2. Navigate to the **Admin Settings** icon in the top-right corner.
3. Select **Admin Center**.

The interface is divided into three primary sections:
* **Setup:** Core account configurations.
* **Governance:** Management of users, groups, and permissions.
* **Monitoring:** High-level usage statistics and conversation tracking.

== Managing Users and Permissions
User management in AgentSpot mirrors the Fotspot structure. You can manage access by assigning specific roles to your existing groups.

=== AgentSpot Privileges
Within the **User Group Permissions** section, you will find a new category called **Agent Spot Control**. There are two primary privileges you can assign:

[cols="1,3"]
|===
| Privilege | Description

| *Can Administer AgentSpot* | Full administrative access to manage connectors, agents, and organization-wide settings.
| *Can Use AgentSpot* | Allows users to log in to AgentSpot and interact with shared agents.
|===

Users will only appear in the AgentSpot user list once they have been assigned a role containing one of these privileges.

== Configuring Connectors
Connectors allow AgentSpot to interact with external applications like Jira, Slack, and Clay.

=== Native Connectors
Fotspot ships with native connectors for popular applications. As an administrator, you have the authority to:
* **Activate/Deactivate:** Enable or disable specific apps for the entire organization (e.g., turning off Slack write-access if desired).
* **Test & Share:** You can activate a connector for yourself to test its functionality before "publishing" or sharing it with the rest of the organization.

=== Custom Connectors (MCP Servers)
If a required application is not in the native list, you can add custom connectors using **MCP (Model Context Protocol) servers**. Simply provide the URL for the MCP server and complete the setup to enable any compatible tool.

=== User Authentication & Security
[IMPORTANT]
====
Connectors use **Individual Authentication**.
====
Even when an admin enables a connector (e.g., Jira), each user must log in with their own credentials. AgentSpot respects all existing permissions within the target app; users will only see data and perform actions they are already authorized to access.

== Agent & Workflow Governance
Administrators have "God Mode" visibility over all agents and workflows created within the organization.

* **Visibility:** Admins can see every agent created, regardless of who the owner is.
* **Business Continuity:** If a user leaves the company, an administrator can step in to manage, edit, or reassign the agents and workflows they created.

== Onboarding Users to Specific Agents
Once agents are created, you must share them with the appropriate teams to make them visible in their dashboard.

1. **Select the Agent:** (e.g., "Lead Generator" or "HR Onboarding").
2. **Assign Access:** Select the specific group (e.g., "Sales Team" or "HR Group").
3. **Set Permission Level:**
** *Use:* User can interact with the agent but cannot change its configuration.
** *Edit:* User can modify the agent's logic or settings.
4. **Save & Share:** The agent will immediately appear in the user's AgentSpot library.

== Monitoring Usage
The Admin Center provides high-level analytics to help you track the ROI and adoption of AgentSpot. You can monitor:
* Total active users.
* Number of conversations.
* Connector usage frequency.
