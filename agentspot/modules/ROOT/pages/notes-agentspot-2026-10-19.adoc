= October 19, 2026
:description: Full release notes for the AgentSpot production release of October 19, 2026.
:page-layout: default-agentspot-release-notes

This production release includes 45 updates. For a summary of recent releases, see xref:notes.adoc[AgentSpot release notes].

== What's new

=== Agents

* *Scout, your default agent:* the default Scout agent is now available to all customers.
* *More memory topics visible:* view more of your saved agent memory topics from the memory management pages.
* *Personal agent memory page:* see your agent-only memories on your personal memory page.
* *New sales and CS agent templates:* the agent template gallery now includes more ready-to-use templates for sales and customer success.

=== Workflows

* *Reconnect connectors from a workflow run:* reconnect a broken connector directly from a workflow run page without losing progress.
* *Edit workflow schedules in place:* view and edit a workflow's schedule directly from its run page.

=== Apps

* *Book 1:1 help from the homepage:* a new "Book 1:1 help" launcher is available on the homepage.
* *Share nudges:* get a nudge to share what you built, and see what others have shared with you.
* *See your most-used agents:* Discover now shows your own most-used agents and how many people are using each workspace item.
* *Your apps on the homepage:* the homepage now shows your own apps instead of an empty first-run state.
* *Reset a stuck app builder:* agent owners can now reset a stuck app-builder session.
* *Distinct identity for every item:* each agent, workflow, and app now has its own distinct identity on the Discover page.

=== Connectors

* *Connector reminders in Slack:* Slack now reminds you to connect a shared agent's connectors when needed.
* *Microsoft 365 connector:* connect Microsoft 365 as a new connector in AgentSpot.

=== Administration

* *See who configured a connector:* connector settings now show which admin configured each connector.
* *Post-login invitations:* new users now receive an invitation after logging in for the first time.

== Improvements

=== Memory

* *More reliable memory clearing:* clearing or deleting saved memory is now more complete and reliable.
* *Fixed profile section editing:* editing a saved profile section no longer fails with a not-found error.
* *Faster memory setting updates:* open chats now pick up memory setting changes starting on their next turn.
* *Trackable memory erasure:* memory erasure requests are now tracked with proof of completion.
* *Fixed memory page navigation:* fixed the agent memory page's back button looping back to the same page.
* *Fixed memory save visibility:* fixed issues where saved instructions were hard to find.

=== Agent chats

* *Easier chat scrolling:* scroll up in a chat while a response is streaming, with a one-click button to jump back down.
* *Shared chat design refinements:* shared agent chats received further design alignment and polish.

=== Workflows

* *Steadier workflow builder sessions:* the workflow builder now preserves your in-progress state across longer editing sessions.

=== Apps

* *Discover and homepage fixes:* fixed several Discover and homepage display issues, including dark-mode styling.
* *Fixed app-builder session recovery:* fixed an issue where a damaged app-builder session could affect its own draft.
* *Steadier top navigation:* the AgentSpot logo now stays next to the back button in the top navigation.
* *Redesigned share dialogs:* share dialogs now match the updated design, including an org-wide access switch.

=== Connectors

* *Clearer connector sign-in errors:* connector sign-in failures now show a clearer, specific message.
* *Improved connector menu:* the connector menu in chat now shows brand icons, short descriptions, and connection counts.
* *Expanded Google Workspace actions:* the Google Workspace connector now supports a broader set of update actions.
* *Steadier Microsoft 365 connection:* Microsoft 365 tool calls now stay connected through token refreshes.
* *Clearer Slack bot feedback:* the Slack bot now shows progress indicators and replies privately when needed.
* *Fixed blocked Slack replies:* Slack replies are no longer blocked just because a connector is not yet connected.

=== Administration

* *Faster audit log exports:* audit log CSV exports now default to the last 24 hours.
