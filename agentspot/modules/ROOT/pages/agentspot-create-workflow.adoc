**Workflows** are designed to automate your repeatable, time-consuming tasks.

== Agents vs. Workflows: What’s the Difference?

Before building, it is helpful to understand how these two features complement each other:

[cols="1,2", options="header"]
|===
| Feature | Description
| **Agents** | Think of these as **People**. They have personalities, specific expertise (e.g., SEO, Design, Sales Support), and you interact with them via conversation to get specialized help.
| **Workflows** | Think of these as **Tasks**. These are automated, repeatable processes (e.g., a "Morning Briefing" or "Deal Monitor") that run in the background to handle admin work and data synthesis.
|===

== Workflow Concepts

Every workflow in AgentSpot is built on three core pillars:

1. **The Trigger:** Currently, workflows run on a **Schedule** (Cron jobs). You decide how often the task repeats (e.g., every morning at 8:00 AM). _Note: Event-based triggers, like a new ticket appearing in Service Now, are coming in future updates._
2. **Sub-Agents:** A workflow isn't just one script; it’s a "team" of specialized sub-agents running in parallel. One might scan Salesforce while another monitors Slack.
3. **The Output:** This is the final action, such as sending a summary message to Slack or dispatching an email.

== Creating a New Workflow

=== 1. Use the AI Chat Builder
Just like creating an Agent, we encourage you to use the **Chat Interface** to build your workflow.
* Instead of manual configuration, type what you want to automate.
* *Example:* "Every morning, scan my Slack channels and Salesforce deals to tell me which leads have gone cold."

=== 2. Configure Your Sub-Agents
The builder will automatically suggest a series of sub-agents.
* **Parallel Processing:** These agents work at the same time to save time.
* **Specialization:** Each sub-agent focuses on one tool or data source.
* **Customization:** You can click into any sub-agent to view its specific instructions or the tools (Connectors) it is using.

=== 3. Define the Synthesis and Output
Most workflows conclude with a "Synthesis Agent." This agent takes the raw data from all sub-agents and combines it into a human-readable format.
* **Select Output Channel:** Choose where you want the result delivered (e.g., a specific Slack channel or your Email inbox).

== Testing and Activation

Before taking your workflow "live," you can perform a test run:

1. **Run Test:** Click the "Test" button to see a live animation of the workflow process.
2. **Monitor Progress:** You can watch as the workflow moves from the trigger through each sub-agent.
3. **Review Output:** Once the run is complete, AgentSpot will show you exactly what information would have been sent to your output channel.
4. **Create:** If you are satisfied with the results, click **Create** to add it to your active workspace.

== Managing Existing Workflows

Once created, your workflows live in the **My Workflows** section.

* **High-Level Overview:** Click on any workflow to see a visual map of the process.
* **Run History:** View the "Last Few Runs" to verify that the automation is performing as expected.
* **Templates:** If your admin has provided templates (like a "Daily Admin Workflow"), you can use these as a "recipe" and simply plug in your specific connectors (e.g., choosing between Gmail/Slack or Outlook/Teams).

[TIP]
====
Workflows are perfect for "painful" repeatable processes. If you find yourself manually checking the same three apps every morning, that is a prime candidate for an AgentSpot Workflow.
====
