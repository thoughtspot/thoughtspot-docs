Welcome to AgentSpot! This guide provides everything you need to know to get started, from your first login to building custom digital assistants.

If you are an administrator responsible for setting up AgentSpot for your company, see xref:agentspot-admin.adoc[].

== Overview
AgentSpot is an AI agent platform integrated with your ThoughtSpot ecosystem. It allows you to leverage pre-built team agents or create your own custom agents that can read data from and take actions within your favorite business applications.

== Before you begin

Make sure you have the necessary permissions to access AgentSpot. To confirm, contact your ThoughtSpot administrator.

To sign in, your user account must have the following roles:

* Can use AgentSpot
* Can manage AgentSpot


== Signing in to AgentSpot

. Sign in to your Org in your ThoughtSpot instance.
. Go to the *Insights* tab and click *AgentSpot* in the left-hand navigation (just below _Home_ and _Spotter_).
. Sign in with the same credentials you use for your ThoughtSpot instance.
+
The AgentSpot home page appears. If you're an admin, you also see *Admin Settings* in the upper-right of your page next to your user menu.
+

+
If you can't sign in or don't see any agents, contact your AgentSpot admin.

== The onboarding journey
Upon logging in, you have two primary ways to begin:

=== Option A: Team Library (Recommended)
The Team Library contains agents and workflows pre-configured by your administrators and the ThoughtSpot team.

* **Why start here?** These agents are fine-tuned for your organization's specific data and needs.
* **How to use:** Browse the library, use filters to switch between *Agents* and *Workflows*, and select one to begin chatting.

=== Option B: Custom creation
If you have a unique use case, you can create a new agent from scratch or branch off an existing template.

== Connecting applications
To provide value, agents require context and the ability to act. If an agent requires external data (e.g., from Notion or Salesforce), you will be prompted to connect.

1. **Identify requirements:** The agent interface will flag if an app is not yet connected.
2. **Authenticate:** Click the **Connect** button.
3. **Authorize:** Complete the OAuth flow in the pop-up window to grant AgentSpot permission.
4. **Active state:** Once connected, the agent can perform deep-context searches and execute tasks (like creating tickets or updating records).

== Managing your agents
When you find a useful agent in the library, you must decide how to keep it:

[cols="1,2,2", options="header"]
|===
| Action | Description | Best For...
| **Save to Team** | Bookmarks the organizational agent. | Standard users who want the latest updates/improvements from admins.
| **Make a Copy** | Creates a private "branch" of the agent. | Power users who want to modify instructions or add private connectors.
|===

== The Agent Creation Studio
If you choose to build your own agent, you will use the **Creation Studio**.

=== The "DNA" of an Agent
* **Instructions:** The "brain" of the agent. Defines persona, mission, and response rules.
* **Skills:** Reusable "how-to" knowledge (e.g., "How to format a deck using the company PowerPoint template").
* **Tools:** Functional capabilities like web search, code interpretation, or the ability to ask clarifying questions.
* **Knowledge (Files & Models):** Upload PDFs/FAQs or connect to ThoughtSpot structured data models.
* **Connectors:** Enables the agent to take action. For example, a **Jira Connector** allows the agent to read tickets and write new bug reports.
* **Starter Prompts:** The suggested questions (bubbles) shown to users at the start of a chat.

[TIP]
====
Use the **AI Conversation Builder** on the left side of the studio. Instead of writing complex rules, simply chat with the builder: *"I want an agent that helps my sales team prioritize leads based on Slack and Salesforce data."* The system will draft the technical instructions for you.
====

== Using Your Agents
Once set up, your agents are available in your sidebar.

* **Chat History:** Resume any previous conversation from the left-hand panel.
* **Search & Filter:** Use the **List View** to find specific agents by category, such as "Marketing" or "HR."
* **Contextual Actions:** Remember that agents with connectors (like Jira or Slack) can perform "last mile" tasks for you, such as drafting and sending messages or filing tickets.
