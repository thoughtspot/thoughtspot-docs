= Sessions and conversations
:last_updated: June 10, 2026
:linkattrs:
:experimental:
:page-aliases:

[.lead]
A *session* is a single conversation with an agent. Within a session, the agent remembers earlier messages so you can ask follow-ups without restating context.

== What a session contains

A session holds:

* The full chat history between you and the agent (your messages and its responses).
* Any files you've uploaded in this conversation.
* Temporary state the agent built up while answering (the data it just queried, the chart it just generated, the tool results it just received).

Sessions are per-user: your conversation is not visible to other consumers of the same agent. Admins can see *that* a session happened (for audit) but not the *contents*, unless your organization has explicitly enabled content logging. ⚠️ Confirm content-logging behavior with [feature owner].

== Session memory vs long-term memory

These are easy to confuse. They're different.

[cols="1,1,1",options="header"]
|===
|Dimension |Session memory |Long-term memory

|Lifetime
|This conversation only.
|Persists across conversations.

|Scope
|This session, this user.
|Per user, per agent, or per organization.

|What it stores
|Chat history, uploaded files, intermediate results.
|Durable facts, preferences, rules.

|Who manages it
|Automatic — the platform handles it.
|Explicitly saved by the agent or user.
|===

For long-term memory, see xref:../04-memory/01-overview.adoc[Memory overview].

== Starting a new session

Open *New conversation* (⚠️ confirm label) in the chat header. A fresh session has no prior chat history and no uploaded files. Long-term memory still applies.

Start a new session when:

* The topic has changed materially and old context would confuse the agent.
* You're getting stuck in a bad pattern (e.g. the agent keeps repeating a wrong assumption).
* You want a clean test run after editing the agent.

== Continuing an existing session

Each session has a stable link. To continue a conversation later:

. Open *Agents* > your agent > *Conversations*. ⚠️ Confirm navigation.
. Pick the conversation you want to resume.

Your conversation history is intact and the agent has the same context it did when you left.

== Sharing a conversation

You can share a conversation link with a colleague who has access to the same agent.

. From the chat, open *Share* (⚠️ confirm label).
. Copy the link and send it to your colleague.
. The recipient sees exactly what you saw, including your messages and the agent's responses.

⚠️ Confirm whether the recipient must already have access to the agent, or whether sharing grants temporary access, with [feature owner].

Do not share conversations containing sensitive personal data with anyone who shouldn't see it.

== Limits

* *Context window* — every session has a maximum amount of conversation history the agent can hold at once. Very long conversations cause the oldest messages to be summarized or dropped. ⚠️ Confirm the context window with [feature owner].
* *Concurrent sessions* — there is a per-user limit on simultaneous active sessions. ⚠️ Confirm the limit.
* *Inactivity timeout* — sessions left idle for a long time may be archived but remain available in *Conversations*. ⚠️ Confirm timeout.

== Best practices

For builders:

* Tell the agent (in instructions) to summarize earlier context at the start of a long conversation. This keeps the most important facts in the window.
* If your agent depends on a value from earlier in the conversation, add a rule: "If the user asked about region X earlier in the conversation, default to region X for follow-ups unless they say otherwise."

For end users:

* Use follow-ups instead of repeating yourself ("now break that down by segment" is better than retyping the whole question).
* Start a new conversation if you're switching topics. The agent will be sharper.
* If the agent forgets a fact you stated earlier, restate it once — and tell the agent's owner via thumbs-down.

== Troubleshooting

[cols="1,2",options="header"]
|===
|Symptom |What to try

|Agent forgets something you said five turns ago.
|You may have hit the context window. Start a new conversation and restate only what matters.

|Conversation list is empty.
|You haven't started any conversations with this agent, or your admin has not enabled conversation history. ⚠️ Confirm behavior.

|Shared link returns "no access."
|Recipient doesn't have access to the agent. Ask your admin to add them to the right group.

|Old conversation looks different from when you left it.
|The agent has been republished. Conversation history is unchanged, but new messages use the new version.
|===
